# 로컬 리서치·판단·질문 기록

PRINCIPIUM·IW·ASK의 새 글과 첨부는 방문한 브라우저의 IndexedDB에 보관한다. 웹 서버에 글이나 첨부를 전송하는 API는 호출하지 않는다. 공개 팀 노트와 가격 기반 관측 요약은 GitHub/Vercel의 계산 결과이고, 새로 등록한 개인 자료와 구분한다.

## 화면 계약

- PRINCIPIUM: 논문/기사·리포트·프라이머 분류와 검색. 제목·메타, 핵심, 아이디어, 근거/데이터/방법, 시사점의5단 상세. 프라이머는 정의·메커니즘·밸류체인·전망으로 제목을 바꾼다.
- IW: 관측·해석/판단·근거·대응을 분리하고 방향·기간·확신도·무효화 조건·재검토 날짜를 기록한다. 저장된 판단을 실제 주문이나 포트폴리오 비중으로 실행하지 않는다.
- ASK: 질문·답변/해석 메모·참조 근거·추가 확인을 구분한다. 사용자 입력을 자동 AI 답변으로 표시하지 않는다.
- 공통: 등록·수정·초안/검토중/검토완료·휴지통·복원·명시적 영구삭제·첨부·백업. 공개 팀 노트는 원본을 수정하지 않고 내 기록으로 복사한다.

제목 관계도의 노드는 문서다. 같은 분류/검색/보관함 조건의 문서가 키워드를 공유하면 연결하고, 선 두께는 공유 키워드 수다. 인과관계가 아니다. 노드 클릭은 상세를 열고 드래그는 위치를 바꾼다. 연결망은 표시된 첫100문서까지이며 제한을 표시한다. 각 문서 내 키워드는 중복을 제거한다. 2~22자 키워드의 문서 빈도로 상위30개를 구면 배치하고 회전 입력으로 탐색한다. 공통 키워드가 없는 문서 사이에는 선을 만들지 않는다. 원본의 제목 노드/공유 키워드 및 구체 구조를 따르되 배치·색은 독립 구현이다.

## 저장·첨부

`research-store.js`의 DB 버전1은 메타데이터와 파일 Blob을 별도 object store에 둔다. 글500건(휴지통 포함), UTF-8 메타데이터2MiB, 첨부64MiB 전체, 파일당8MiB·기록당12개가 현재 한도다. 동일 SHA-256 파일은 여러 글에서 공유한다. 파일 이름은 각 글의 참조에 남긴다.

PDF·PNG·JPEG·WebP만 받는다. 실제 앞부분의 파일 서명으로 형식을 확인하고 전체 바이트의 SHA-256을 계산한다. 이는 파일 포맷 전체를 해석하거나 악성 문서를 검사했다는 의미는 아니다. PDF는 다운로드로 제공하고 래스터 이미지만 요청할 때 Blob URL로 미리 본다. 미리보기 URL은 화면 갱신/이동 때 반환한다. SVG/HTML 첨부를 실행하지 않는다.

본문·첨부의 저장/삭제는 같은 IndexedDB 트랜잭션에서 완료되어야 성공으로 표시한다. 용량 부족이나 중간 실패는 기존 상태를 보존한다. 오래된 창의 전체 수정은 revision 비교로 거부한다. 새로 읽은 뒤에도 편집을 시작한 기록의 변경 이력이 다르면 저장을 거부하고 입력을 유지한다. 사용자는 최신 기록을 다시 편집하거나 입력을 새 사본으로 저장할 수 있다. IndexedDB의 비동기 요청·트랜잭션 완료 구분은 [MDN의 저장 안내](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)와 [트랜잭션 설명](https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction)을 따른다.

## 이전 메모·백업

이전 `sangsangin-journal-v1-<module>` 값은 자동 삭제/변환하지 않는다. 버튼으로 명시적으로 가져오며 원문을 보존한다. 동일 제목/본문/시각의 이전 메모는 같은 ID를 얻고 반복 가져오기에서 중복을 제외한다.

백업 JSON은 선택한 모듈의 글과 연결된 첨부를 base64로 함께 담는다. 최대90MiB이며 가져오기 전에 형식·해시·크기·참조를 검증한다. 동일 기록은 중복을 건너뛰고, 같은 ID의 내용이 다르면 새 ID의 사본으로 추가한다. 기존 글을 덮어쓰지 않는다. 영구 삭제 때도 다른 글이 사용하는 파일은 남긴다.

저장 영역은 브라우저와 웹사이트 주소별로 분리된다. GitHub Pages의 기록을 Vercel로 옮길 때는 기존 사이트에서 내보낸 JSON을 가져온다. 브라우저 데이터 삭제·비공개 창 종료 등의 경우에는 로컬 자료를 잃을 수 있으므로 백업을 별도로 보관한다. 서버 백업이나 팀 동기화를 제공한다고 표시하지 않는다.

## 검증과 남은 범위

`test_research_store.cjs`는 IndexedDB 표준 API를 구현한 fake-indexeddb6.2.5에서 실제 저장 코드를 실행한다. 파일 해시·전송 복원·용량/중간 실패의 원자성·다른 창 충돌·참조 삭제·한글 바이트 한도를 검사한다. `test_research_notes.cjs`는 파싱한 화면과 실제 이벤트 콜백으로 양식·첨부·검색·노드 이동·입력 보존/사본·휴지통·이전 메모·백업을 검사한다. 브라우저 레이아웃 QA가 아니다.

팀 공용 DB/로그인, 서버의 공개 게시/방문 통계, PDF 자동 추출 및 LLM 요약, 원본 IW29개 판단 항목/두차트, ASK의 기간별 추세/테마/모듈별 집계는 추가 구현 대상이다. 새 저장 기능을 이들 전체 기능의 완료로 세지 않는다.
