# 기능별 화면 이름

화면 제목·탐색 메뉴·현재 위치·시장 요약의 모듈 카드·현황판·구현 문서는 `docs/modules.js`의 기능명을 기준으로 표시한다.

| 기능명 | 내용 |
|---|---|
| 통합예측 | 지수·종목·거시 전문가 모형과 예측 검증 |
| 기업분석 | 관계 지도·기업 상세·관심도·촉매·리서치·결정 원장 |
| 위성사진 | 시설별 RGB·NDVI 관측과 촬영 이력 |
| 위성·지구관측 | 시설·지진·궤도 위성을 보는 3D 지구본 |
| 업종·자산지도 | 업종 관계와 자산군 연간 수익률 |
| 글로벌 공급망 | 국가 교역·기업 위치·밸류체인 |
| 국면 | 경제·시장 국면과 전이·발표 일정 |
| 수급·위험 | 투자자 수급·파생·옵션·쏠림·위험지표 |
| 실적·컨센서스 | 보고 실적과 시장 추정치 |
| 성장 컨센서스 | 이익 성장·이익률·주가 성과 |
| 리서치 자료실 | 문서 탐색과 개인 연구 기록 |
| 주간 기록 | 주간 관측·해석·근거·대응 |
| 시장 요약 | 계산 결과에 근거한 시장 점검 |

전체 25개 이름은 [화면별 문서](MODULES.md)를 따른다. 기존 URL 해시·JSON의 module/id·기업 식별자·개인 기록의 저장 키는 유지한다. 사용자 문서의 본문을 일괄 수정하지 않는다.

정기 계산의 최종 공개 출력에는 `pipeline/display_names.py`를 적용한다. 과거 계산 캐시의 표시 문구도 기능명으로 바꾸며 수치·날짜·객체 키·출처 URL은 유지한다. 실제 OCR 라이브러리 Tesseract.js의 제품명·라이선스는 이 변경 대상이 아니다.

이번 변경으로 예측 모형을 다시 학습하거나 원자료를 수집하지 않았다. 학습 캐시 서명에 포함되는 모형 소스의 바이트도 보존한다. 표시 이름 변경은 미구현 기능의 완성을 의미하지 않는다.
