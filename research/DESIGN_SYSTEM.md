# 화면 디자인과 공간 차트

2026-09-11 디자인 전용 Worktree 변경. 사용자가 지정한 [Apple Intelligence 페이지](https://www.apple.com/apple-intelligence/)의 큰 제목, 충분한 여백, 둥근 카드, 제한된 강조색과 제품 중심 구성을 참고했다. Apple의 이미지·로고·폰트 파일·소스는 공개 출력에 포함하지 않는다. 참조 화면 캡처와 검수 이미지는 저장소 밖 공동 폴더에 보존한다.

## 현재 디자인 기준 · 흰색과 무광 데이터 마커

사용자의 최종 피드백(구슬 같은 객체, 검은 배경, 폰트와 그래프의 분리, 정렬 부족)에 따라 이전의 흑연색/유리구슬 연출을 대체했다. 아래 변경 이력보다 이 절이 현재 기준이다.

- 본문은 흰색, 그래프는 거의 흰 #fafbfd, 경계는 #e8ebef. 본문·축·범례·툴팁·전체 화면이 동일한 글꼴과 웜그레이/세이지/브라운 체계를 사용한다. SF 시스템 우선 및 로컬 Pretendard, 표 수치는 tabular-nums를 적용한다.
- 공통 orbPaint API는 이제 무광 단색을 반환한다. 반사점, 짙은 구형 음영, 외곽 발광을 제거했다. 실제 3D 투영·깊이 순서·축·드래그 조작은 그대로다. 지구본 자체의 지형/해양 표현은 별도다.
- Overview 마커 반지름은 기존 크기 변수에 대한 3.5~9.5 화면 단위의 단조 매핑이다. 모멘텀 후광은 채워진 광원에서 얇은 링으로 바꾸고 반경/불투명도에 같은 변수를 유지한다. 데이터가 없는 후광을 만들지 않는다. 연속 색은 -1.5~+1.5z 범위의 브라운 명도 매핑이며 양 끝은 포화된다. 좌표의 전체 관측 자동 맞춤과 구분한다.
- 4시점은 작은 링/선택 가능한 날짜 범례로 연결한다. 겹치는 날짜 문구는 점 주변에서 없애고 범례에 보존한다. 그래프 정의는 SVG 바닥에서 반응형 HTML 주석으로 옮겨 같은 본문 글자 크기로 읽게 했다.
- Overview 제목/상태와 관측일/조작부를 한 헤더로 묶었다. 제목→캡션→그래프→주석→날짜→선택 수치→비교 패널 순서다. 레이더와 6축 수치의 캡션·구분선·시작선을 맞추고 수치 카드에서 내부 role 이름을 제거했다.
- MAXIMUS의 장식 구체/궤도는 정렬된 무광 컴포넌트로 바꾸었다. 연결선 두께의 실제 가중치, 10개 전문가와 모든 출력은 그대로다. 관계망의 내장 검은 SVG 배경도 흰색 계열로 변경했다.

모든 폭에서 여는 탐색 메뉴, 기존 제목과 설명, 자료 기준일과 부분 구현 상태를 유지한다. 홍보 문구·추가 CTA·계산 변경은 없다. 과거 스타일의 구현 기록은 아래에 남아 있으나 현재 화면 계약은 이 절을 따른다.

## 공간 차트 적용 범위

| 장면 | 표시 개선 | 조작/검증 경계 |
|---|---|---|
| 성장주 3D | 무광 마커, 바닥 격자, 깊이 정렬, 원래 축/크기/색 | 기울기·회전·줌, 종목 선택 |
| 변동성 표면 | 깊이 순서, 셀의 날짜/기간/꼭짓점 평균 툴팁 | 시점·기울기·회전·줌 |
| 국면 36개월 궤적 | 무광 마커, 기존 5축/사분면/최신점 | 날짜/점 선택, 원수치 상세 |
| Overview 상태 궤적 | 기존 6/5축·후광·결측 단절 유지 | 날짜/점 선택, 기울기·회전·줌 |
| Overview 적층 레이더 | 4시점 벽면과 층 유지 | 독립 회전·기울기·줌 |
| Overview 주도주 | 기존 시총/모멘텀/성장 크기·배치에 명암 | 독립 회전·기울기·줌, 종목 선택 |
| 공식 분류 관계망 | 깊이 정렬, 명암, 종류 범례 | 객체 선택, 기울기·회전·줌 |
| 사업 관계망 | 흰색 영역, 무광 마커, 종류 범례 | 기존 필터/전파계수 유지, 공통 카메라 |
| 국가 지구본 | 구체 명암, 라벨 충돌 완화, 선택 테두리 | 경도·위도·줌, 국가 선택 |

각 장면은 기존 좌표의 SVG 투영이다. WebGL 모델이나 추가 예측 모형을 도입하지 않는다. 일반 선·막대·캔들·표는 비교 축과 단위가 바뀌지 않도록 유지한다. 축에 없는 제3의 값을 만들거나 원자료를 수정하지 않는다. 3D 확대는 화면 배율이며 통계 범위의 변경이 아니다. 겹친 실제 관측을 인위적으로 흩어 놓지 않는다.

## 통합과 검수

- `experience.css`와 `index.html`의 스타일 링크를 함께 적용한다. 기존 PDF/OCR/데이터 스크립트 순서를 바꾸지 않는다.
- 공통 카메라/명암 유틸리티는 `analysis-charts.js`에 있으며 네 렌더러에서 사용한다. 관련 JavaScript 변경을 한 묶음으로 통합한다.
- 입력 프레임을 합치는 동작을 반영해 오프라인 DOM fixture와 Overview/관계망 검사의 프레임 실행을 갱신했다. 계산/데이터 검사를 약화하지 않는다.
- 검수 명령과 브라우저 범위는 [차트 조작 가이드](CHART_INTERACTION_GUIDE.md)를 따른다. 실제 모바일 하드웨어, 스크린리더, 다른 브라우저와 모든 세부 탭의 픽셀 동등성은 별도 검수가 필요하다.
- 로컬 완료 커밋과 최종 검수 결과는 저장소 밖 `DESIGN_CHARTS_STATUS.md`가 정본이다. 메인 담당이 기능 변경과 통합해 검증·게시한다.


## 직접 조작과 객체 재질 (후속 사용자 요구)

카메라 슬라이더와 모드/시점 버튼 중심의 조작을 제거했다. 화면을 직접 드래그·클릭·휠·핀치하며 하단에는 복원/전체화면만 남긴다. TESSERACT의 판·구체·궤적·후광과 적층 레이더를 개별 재질로 다시 그렸다. 장식과 데이터 후광을 구분하며 데이터 의미는 유지한다. 조작별 접근성과 검증 범위는 차트 조작 가이드를 따른다.


## 2026-09-11 공간 무대 재구성

사용자가 두 참고 페이지의 재검토를 명시적으로 요청해 브라우저에서 Overview 홀로그램/레이더와 Apple Intelligence의 큰 제품 영역, 명암 대비, 둥근 탐색 요소, 반사광 표현을 직접 비교했다. 참고 제작자의 자료·이미지·코드·링크는 공개 출력에 포함하지 않았다.

- 밝은 바깥 화면과 흑연색 3D 무대를 구분한다. 본문 제목/설명은 기존 문구를 유지하고 홈 과대 여백을 줄인다.
- TESSERACT/CROWDING에 12개 모서리의 공간 경계, 분명한 바닥 높이, 발광 궤적, 현재 날짜 표식을 추가한다. 당시 고정 z 표시 범위는 아래 2026-09-11 자동 범위 변경으로 대체되었다.
- 네 날짜 범례는 SVG 밖의 선택 버튼으로 옮겨 작은 화면에서도 원수치를 선택할 수 있다. 선택 상태를 aria-pressed로 알린다.
- 주도주 장면은 기존 시총 기반 동심 위치에 종방향 격자를 더한다. 중심 광원은 장식이며 새 관측 또는 예측 신호가 아니다.
- 회전 후 짧은 감속을 적용하며 blur/reset/dispose에 취소한다. 모션 감소 설정은 감속을 끈다. 사용자가 시작하는 자동 회전은 유지한다.
- 공통 그래프 무대·선·카드·숫자·필터 스타일을 정리하되 모든 시계열을 임의 3D로 바꾸지 않는다.


## 2026-09-11 넓은 배치와 관측 범위 맞춤

사용자의 후속 요청에 따라 Overview와 국면 3D 궤적의 고정 z 표시 절단을 없앴다. 전체 유효 관측과 0을 포함하는 축별 범위에 여유를 더한다. 점, 숫자 눈금, 0 평면과 사분면은 같은 좌표 변환을 사용한다. 원래 z·원단위·시계열은 변경하지 않는다. 축마다 범위가 다르므로 화면의 각도·거리를 축 사이의 동일한 z 거리로 읽지 않는다. 고정 비교 범위를 쓰는 레이더의 계약은 유지한다.

고정 사이드바를 모든 폭에서 여는 메뉴로 바꾸고, 주 3D/시계열은 전체 행에 배치한다. TESSERACT 아래는 레이더와 현재 6축 수치가 좌우 비교이며 CROWDING 아래는 주도주와 레이더가 좌우 비교다. 작은 화면에서는 순서대로 쌓인다. MAXIMUS 대상별 예측은 전체 행으로 펼치고, 10전문가 연결도를 곡선 연결·유리 노드·가중치 선 두께로 다시 그렸다. 실제 가중치·예측·68/95% 팬은 동일하다.

글꼴은 Apple 시스템 글꼴 우선, Windows/Korean은 로컬 Pretendard Variable이다. 배포 글꼴은 OFL-1.1 라이선스와 함께 포함되며 config/ui_font_vendor.json의 크기·SHA256을 검증한다. 글꼴 이외의 바이너리는 추가 허용하지 않는다. index.html에서 수정한 렌더러와 스타일의 버전을 지정해 이전 미리보기 캐시가 남는 경우를 방지한다.

계층적 제목과 가는 구분선, 평면 정보 영역으로 중첩 카드 프레임을 제거했다. 기존 제목·설명·데이터 상태는 보존하고 홍보 문구를 추가하지 않았다. 직접 드래그·휠·키보드·전체 화면 조작은 유지한다.


## 최종 추가 제약 · 파란색 금지와 주도주 표식

사용자가 파란색 사용을 전면 금지했다. 새 UI의 강조색·선택 테두리·범례·마커는 차콜/웜그레이/브라운/세이지다. presentation.js는 CSS 규칙 및 동적 SVG/인라인 스타일의 색상 속성에만 같은 팔레트를 적용한다. 그래프가 날짜 변경이나 회전으로 다시 그려져도 적용되며 데이터 JSON, 좌표, 텍스트, 파일/이미지 내용은 변경하지 않는다. 불투명도와 밝기 관계를 유지하고 범례와 계열을 같은 변환으로 처리한다. 이 스크립트는 experience.css 뒤, app.js 앞에 로드되어야 한다. 고정 수치 외부 요청이나 라이브러리 의존성은 없다.

주도주의 반복 동심원과 원형 마커는 5개 계단형 윤곽과 얇은 다이아몬드 판으로 대체했다. 중심 거리의 로그 시총 순서, 크기의 성장률 단조 매핑, 색의 모멘텀 변수를 유지한다. 현재 색상은 브라운→세이지이며 반경 기반 화면 크기 매핑을 면적 정비례라고 표현하지 않는다. 10개 종목 라벨은 모든 표식/기존 라벨과 충돌을 최소화하는 후보 위치를 고르고, 표식 위에 별도로 그려 가려지지 않게 한다. 원수치 선택·드래그·핀치·복원은 유지한다.

검수: 10개 대표 기본 화면의 1440px/390px 배치 확인, DOM에서 보이는 글자/채움/선/배경/테두리의 파란 계열 색상 0개 확인. 주도주 10개 표식과 라벨, 날짜 선택, TESSERACT 회전/복원 동작 확인. 단위검사는 hex/RGB/HSL 색 변환·알파 보존·멱등성 및 10종목/5윤곽/입력 불변을 포함한다. 모든 중첩 화면이나 실제 모바일 장치를 확인했다는 의미는 아니다.
