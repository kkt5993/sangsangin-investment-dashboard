# 차트 표시와 조작

이 문서는 정적 스냅샷의 표시 계층을 설명한다. 데이터의 운영·부분 구현 상태는 기존 모듈별 계약과 화면 표시를 따른다.

## 일반 차트

- RS/모멘텀의 기존 단일 계열 차트는 포인터와 좌우 방향키, Home/End로 관측을 확인한다.
- AnalysisCharts.line의 범례는 HTML에서 줄바꿈하며, 오른쪽 축과 점선 계열을 표시한다. 포인터 또는 좌우 방향키로 날짜와 원래 정밀도의 값을 읽는다. 해당 날짜에 없는 계열은 관측 없음으로 표시하며, 임의 보간하거나 마지막 값을 채우지 않는다.
- 좁은 화면의 차트와 표는 내부에서 가로 스크롤한다. 차트의 축 범위, 기간, 계열과 가이드를 화면 폭에 맞춰 생략하지 않는다.

## 그래프 직접 조작

- 그래프 자체를 드래그하면 회전·기울기가 함께 바뀐다. 화면의 회전/기울기/확대 슬라이더와 모드·시점 선택 툴바는 제거했다. 기존 내부 카메라 상태는 숨겨진 입력과 렌더러 계약으로 유지한다.
- 그래프를 클릭/포커스한 뒤 일반 휠로 확대한다. 포커스하지 않은 그래프에서는 일반 페이지 스크롤을 유지한다. Escape 또는 다른 곳 클릭으로 포커스를 해제한다. Ctrl+휠도 지원하며 기존 사업 관계망의 일반 휠 확대는 유지한다.
- 한 손가락으로 회전·기울기, 두 손가락으로 확대와 이동을 동시에 조작한다. 그래프 바깥은 페이지 스크롤 영역이다. Shift/우클릭 드래그는 이동이며 Shift+방향키도 사용할 수 있다.
- 방향키 회전/기울기, +/− 확대, Home/더블클릭/↺ 복원으로 동일 기능에 접근한다. 하단 ⛶는 전체 화면이며 Escape로 종료한다. 이동은 SVG viewBox만 바꾸며 원자료 좌표를 변경하지 않는다. 재렌더링 후에도 이동 위치가 유지된다.
- 관측 점을 클릭/탭하면 원수치 상세가 표시된다. TESSERACT/Overview 관측은 키보드 Tab과 Enter/Space로도 선택한다. 호버 수치 카드는 화면에서 선택 가능한 객체에 표시한다. 겹친 관측은 기존 날짜/종목 목록에서도 선택 가능하다.

## 재질과 데이터 계약

- TESSERACT와 Overview의 사분면은 얇은 반투명 판, 관측은 반사광·윤곽·깊이 순서가 있는 구체, 궤적은 얇은 선과 낮은 밝기의 외곽선으로 표시한다. 후광은 기존 모멘텀 자료를 나타내므로 장식 목적으로 모든 점에 만들지 않는다.
- 적층 레이더의 4시점 면과 벽은 날짜별 그라데이션을 사용한다. 모든 축, 시점·날짜, ±2z 반경과 자료 부족 처리는 유지한다. 공통 구체 재질은 성장주·국면·주도주·관계망·지구본에도 적용한다.
- 성장주/표면/국면 및 Overview/공식 관계망의 원근은 화면 투영이다. 원래 값과 색/크기의 의미는 변경하지 않는다. 궤적의 표시 범위는 전체 관측과 0을 포함하도록 자동 조정한다. 성장주 크기 미확보는 기존 동일 크기 규칙을 따른다. 표면의 색은 낮은 청색에서 높은 보라색으로 정리했다.
- 36개월 궤적의 결측 단절, 5/6축 정의, 최신 관측, 레이더 패널과 데이터 기준일을 보존한다. 화면 조작은 데이터 기간이나 계산 결과를 바꾸지 않는다.

## 구현 및 검사

`docs/analysis-charts.js`는 기존 렌더링 API에 선택적 확대 인자를 더한다. `surface(c, yaw, count, zoom, tilt)`와 `hologram(c, yaw, zoom, tilt)`의 기존 호출도 유효하다. `bindLines(container)`는 새 시계열 출력에 관측 읽기를 연결한다. 별도 코드가 차트 HTML을 교체했다면 새 컨테이너에 다시 호출한다.

`bindCamera(canvas, options)`는 각 렌더러의 read/write/draw/reset 콜백을 연결한다. 투영과 입력 계약은 렌더러가 소유하고, 카메라는 전달받은 화면 상태만 바꾼다. 반환된 dispose는 Overview/관계망의 탭 종료 시 호출한다. 정적 장면의 예약된 단발 렌더링도 DOM 연결 해제 후 건너뛴다.

회전 입력은 requestAnimationFrame으로 합쳐 DOM 교체를 프레임당 한 번으로 제한한다. 사라진 컨테이너에는 예약된 렌더링을 실행하지 않는다. 시계열의 날짜 목록과 계열별 값은 최초 조작 시 한 번 구성하며, 포인터의 가장 가까운 날짜는 이진 탐색한다.

`node scripts/test_extended.cjs`가 표시 범위·점 개수·입력 불변·범례·정밀도 검사를 포함한다. 실제 브라우저 검사는 외부 테스트 도구의 Playwright와 로컬 Edge를 사용한다:

```powershell
# 별도 터미널에서 docs 미리보기 서버를 실행한다.
python -m http.server 8789 --bind 127.0.0.1 --directory docs
# Playwright를 제공하는 외부 node_modules를 NODE_PATH로 설정한다.
$env:CHART_QA_DIR = '<저장소 밖 검수 폴더>'
$env:CHART_QA_SWEEP = '1' # 기본 25탭의 3너비 레이아웃도 검사
node scripts/test_chart_interactions.cjs
```

브라우저 검사는 대표 9개 화면을 1440/1024/390px에서 확인한다. 크게 보기/종료, 드래그·기울기·키보드·관측 선택·터치/핀치·모바일 메뉴를 확인한다. 390px 터치는 Edge의 CDP 에뮬레이션이며 실물 휴대폰 검사가 아니다. 전체 세부 탭의 픽셀 동등성, 스크린리더, 다른 브라우저, 실제 PDF/OCR 업로드와 인쇄/PDF 출력은 이 검사 범위에 포함되지 않는다. 기존 저장/PDF/OCR 동작은 확장 회귀 검사로 확인한다. 전후 이미지와 성능 측정 결과는 저장소 밖 공동 검수 폴더에 보관한다.


### 공간 무대 후속

TESSERACT/CROWDING의 네 날짜 버튼으로 원수치를 바로 선택한다. 회전 드래그를 놓으면 짧게 감속하며, 다시 누르거나 포커스를 옮기거나 복원하면 즉시 멈춘다. 모션 감소 설정에서는 감속하지 않는다. 흑연색 그래프 무대 안의 원자료 의미와 표시 범위는 종전과 같으며, 현재 날짜 표식은 항상 최신 관측을 뜻한다.


## 2026-09-11 넓은 배치와 관측 범위 맞춤

사용자의 후속 요청에 따라 Overview와 국면 3D 궤적의 고정 z 표시 절단을 없앴다. 전체 유효 관측과 0을 포함하는 축별 범위에 여유를 더한다. 점, 숫자 눈금, 0 평면과 사분면은 같은 좌표 변환을 사용한다. 원래 z·원단위·시계열은 변경하지 않는다. 축마다 범위가 다르므로 화면의 각도·거리를 축 사이의 동일한 z 거리로 읽지 않는다. 고정 비교 범위를 쓰는 레이더의 계약은 유지한다.

고정 사이드바를 모든 폭에서 여는 메뉴로 바꾸고, 주 3D/시계열은 전체 행에 배치한다. TESSERACT 아래는 레이더와 현재 6축 수치가 좌우 비교이며 CROWDING 아래는 주도주와 레이더가 좌우 비교다. 작은 화면에서는 순서대로 쌓인다. MAXIMUS 대상별 예측은 전체 행으로 펼치고, 10전문가 연결도를 곡선 연결·유리 노드·가중치 선 두께로 다시 그렸다. 실제 가중치·예측·68/95% 팬은 동일하다.

글꼴은 Apple 시스템 글꼴 우선, Windows/Korean은 로컬 Pretendard Variable이다. 배포 글꼴은 OFL-1.1 라이선스와 함께 포함되며 config/ui_font_vendor.json의 크기·SHA256을 검증한다. 글꼴 이외의 바이너리는 추가 허용하지 않는다. index.html에서 수정한 렌더러와 스타일의 버전을 지정해 이전 미리보기 캐시가 남는 경우를 방지한다.

계층적 제목과 가는 구분선, 평면 정보 영역으로 중첩 카드 프레임을 제거했다. 기존 제목·설명·데이터 상태는 보존하고 홍보 문구를 추가하지 않았다. 직접 드래그·휠·키보드·전체 화면 조작은 유지한다.


최종 검수: Python 214개, 두 공개 데이터 검증기, charts/dashboard/extended JS 검사 및 변경 JS 구문 검사 통과. 내장 브라우저에서 1440px·390px 폭의 Overview/MAXIMUS/Growth/Dynamics/Regime/RS/ML/Globe/Aragorn/Dragonglass 기본 화면을 확인했다. ML의 긴 제목 줄바꿈 문제를 수정한 뒤 390px에서 다시 확인했다. TESSERACT 직접 드래그가 투영을 변경하고 Home이 원래 투영을 복원함을 실제 DOM으로 확인했다. 이전 스크립트 캐시와 구분해 새 버전의 SVG 크기·객체를 확인했다. 실제 모바일 장치, 모든 중첩 탭 및 모든 브라우저에 대한 검수는 아니다.


## 흰색·무광 후속 디자인

흑연 무대와 유리 구체 재질은 현재 폐기되었다. 같은 폰트의 흰색 본문/연한 그래프/툴팁/전체화면, 무광 마커, 절제된 축과 궤적을 사용한다. Overview 크기 변수는 3.5~9.5 화면 단위, 모멘텀은 얇은 링의 반경/불투명도다. 색 변수는 기존 -1.5~+1.5z 포화 범위를 브라운 명도로 표현하며 HTML 범례에 수치를 적는다. 원래 z와 원단위 및 좌표의 자동 범위는 변경하지 않는다.

개요의 선택 수치 출력은 주 그래프 바로 아래로 옮겼다. 네 날짜는 여전히 버튼/키보드로 선택할 수 있고 그래프의 점 클릭/드래그/핀치/휠/복원 API는 동일하다. 헤더, 두 지원 패널, 축/주석의 정렬과 글꼴을 통일했다. MAXIMUS 연결도의 전문가 수·가중치·출력 수는 동일하며 구체와 장식 궤도만 컴포넌트로 대체했다.


## 최종 추가 제약 · 파란색 금지와 주도주 표식

사용자가 파란색 사용을 전면 금지했다. 새 UI의 강조색·선택 테두리·범례·마커는 차콜/웜그레이/브라운/세이지다. presentation.js는 CSS 규칙 및 동적 SVG/인라인 스타일의 색상 속성에만 같은 팔레트를 적용한다. 그래프가 날짜 변경이나 회전으로 다시 그려져도 적용되며 데이터 JSON, 좌표, 텍스트, 파일/이미지 내용은 변경하지 않는다. 불투명도와 밝기 관계를 유지하고 범례와 계열을 같은 변환으로 처리한다. 이 스크립트는 experience.css 뒤, app.js 앞에 로드되어야 한다. 고정 수치 외부 요청이나 라이브러리 의존성은 없다.

주도주의 반복 동심원과 원형 마커는 5개 계단형 윤곽과 얇은 다이아몬드 판으로 대체했다. 중심 거리의 로그 시총 순서, 크기의 성장률 단조 매핑, 색의 모멘텀 변수를 유지한다. 현재 색상은 브라운→세이지이며 반경 기반 화면 크기 매핑을 면적 정비례라고 표현하지 않는다. 10개 종목 라벨은 모든 표식/기존 라벨과 충돌을 최소화하는 후보 위치를 고르고, 표식 위에 별도로 그려 가려지지 않게 한다. 원수치 선택·드래그·핀치·복원은 유지한다.

검수: 10개 대표 기본 화면의 1440px/390px 배치 확인, DOM에서 보이는 글자/채움/선/배경/테두리의 파란 계열 색상 0개 확인. 주도주 10개 표식과 라벨, 날짜 선택, TESSERACT 회전/복원 동작 확인. 단위검사는 hex/RGB/HSL 색 변환·알파 보존·멱등성 및 10종목/5윤곽/입력 불변을 포함한다. 모든 중첩 화면이나 실제 모바일 장치를 확인했다는 의미는 아니다.
