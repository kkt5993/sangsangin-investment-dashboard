# 개발 순서

1. **학습과 설계:** 26개 화면의 역할·입력·출력·검증 과제 정리. 현재 공개 페이지의 범위입니다.
2. **가격 모듈:** RS·모멘텀·ETF를 작은 fixture로 검증하고 벤치마크·통화·배당 기준을 고정합니다.
3. **거시와 실적:** 발표일·수정 이력·회계연도·컨센서스 vintage를 보존하는 수집기를 만듭니다.
4. **위험과 배분:** 포트폴리오의 시점별 비중·비용·노출과 과거 성과를 구분합니다.
5. **예측:** 단순 기준 모델에서 시작해 시간순 검증, 최종 홀드아웃, 확률 보정, 비용 후 성과를 확인합니다.
6. **온톨로지:** 객체 ID·근거·관계 방향을 검증하고 팀 의사결정 원장과 사후 평가를 연결합니다.
7. **운영:** 불변 스냅샷·원자적 발행·실패 시 직전 정상본·신선도 표시를 갖춥니다.

정기 작업과 외부 API는 향후 구현 대상입니다. 현재 저장소에는 자동 수집 일정이나 거래 기능이 없습니다.
