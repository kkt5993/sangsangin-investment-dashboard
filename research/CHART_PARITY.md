# 차트 구조 대응표

색상·글꼴은 독립적으로 작성한다. 보존 대상은 가로/세로축의 의미·단위, 비교 대상, 기간, 기준선, 계열 수와 패널 구성이다. 원본 PNG는 GitHub에 넣지 않고 로컬 보존본을 참조했다.

가독성을 위해 좁은 창에서는 차트를 한 열로 배치한다. 차트는 SVG viewBox를 사용하고, 표/긴 막대는 가로 스크롤을 제공한다. 선 차트는 마우스와 키보드 좌우/Home/End로 날짜별 값을 확인할 수 있다.

## 검증

- Python 단위 검증: 수익률 분모의 위치·%/%p·휴장 교집합·z 표준편차·YTD·미래 데이터 추가 불변성·평탄 계열·결측·동점 순위.
- JS 차트 검증: RS 기준선 5개·단일 계열·중앙 음영, 모멘텀 0선·양음 영역, 값 누락과 단위·이스케이프.
- 실제 스냅샷의 HTML 출력 검증: RS 미국 17개 차트, 모멘텀 32개 곡선, 네 가지 그룹의 행 수, 필터 재요청 없음, 비동기 경로 전환.
- 배포 파일 검증: JSON 표준·시계열 정렬·날짜 범위·수치 유한성·차트 수·공개 파일 크기·로컬 링크·비밀정보 패턴.

이 검증은 실제 브라우저에서의 시각·사용성 테스트를 대체하지 않는다. 브라우저 픽셀 비교는 수행하지 않았다. 계산 검증과 원본 동등성도 구분한다.
