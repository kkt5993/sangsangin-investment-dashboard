# 다음 구현·검증 순서

가격·거시·재무·모델·관계·기록 화면을 연결했다. 현재 범위는 [탭별 현황](IMPLEMENTATION_STATUS.md)을 기준으로 삼는다. 아래는 연결된 탭을 원본의 전체 범위와 실무 운용 수준으로 보완할 작업이다.

1. **원본과 수치 계약 비교:** 비공개 파라미터, 국내 축약 상품명의 실제 원천, z/누적 수익률·모델 정규화 차이를 제작자와 확인한다. 색보다 축·표식·패널·날짜 비교를 우선한다.
2. **시점 데이터:** 경제지표 발표일과 ALFRED 빈티지, 역사 구성종목, 정확한 실적 발표 시각과 수정 이력을 쌓는다. 최신 수정값으로 과거 실시간 성과를 주장하지 않는다.
3. **성장과 이벤트:** 글로벌 FY1/FY2 영업이익·순이익 컨센서스, PEAD·내부자·공매도·13F의 이벤트 원장을 연결한다. 기존 국내 QuantiWise는 날짜를 보존해 읽는다.
4. **원본 고급 모델:** ML의 Boruta·SHAP·DL, MAXIMUS 10전문가·게이트·SIS, 멀티에셋 ML 배분을 설정·비용·OOS 검증과 함께 확장한다. 현재 3모델과 역변동성 기준모형의 결과는 계속 구분한다.
5. **관계의 근거:** DRAGONGLASS의 시설·위성·공급망 관측, 지구본 교역 데이터, geo-economics 뉴스 원장을 연결한다. 수집되지 않은 값을 그림을 채우려고 만들지 않는다.
6. **팀 운영:** 개인 localStorage 원장을 팀 공유 DB·권한·감사 이력으로 발전시킨다. 업로드·동시 편집·ROSENBACH에는 인증 서버와 소유자 데이터 계약이 필요하다.
7. **운용 검증:** 전략별 거래비용·차입·리밸런싱과 역사 유니버스 OOS를 확인하고, 불변 데이터 빈티지·원자적 배포·실패 시 직전 정상본을 정식 운영 절차로 만든다.

수집과 계산은 이 PC에서 수동 실행한다. 원자료는 저장소 밖에 두고 기본 누적32MiB를 초과하기 전에 사용자에게 묻는다. 이번 수집은 무손실 압축으로 한도 안에 들어왔다. 자동 일정·거래 기능은 등록하지 않았다.
