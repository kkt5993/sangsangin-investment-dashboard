# 실적 세부 화면의 계산 계약

원본은 재접속 없이 보존한 `app.js`의 `globalEarnHTML`, `estimateVerifyHTML`과 `earnings.json`의 구조만 확인했다. 값은 원본에서 복제하지 않고 이 PC에서 수집·계산한다. 구현은 `pipeline/earnings_details.py`, 화면은 `docs/earnings-views.js`이며 전체 정기 build의 `extend`에 연결했다.

## 화면과 단위

| 세부 화면 | 패널과 상호작용 | 자료 |
|---|---|---|
| 글로벌 순이익 | 20행, 동일 USD bn 축·굵은 FY1 막대·얇은 FY2 막대·회색 실제 NI 선·3값·환산 원장 | 현재 연구 기업 표본의 최신 연간 NI 상위20. 세계 전체 순위 아님 |
| 국내 추정 상세 | 삼성전자·SK하이닉스 각각 OP/지배 NI 2패널, 과거3연도 실제·다음2연도 추정, 가격/목표가/PER/시총/영업이익률·출처 | Yahoo 실제 재무 + 별도 날짜의 로컬 QuantiWise 추정 |
| 미국 추정 상세 | GOOGL/NVDA/MSFT/AMZN/AAPL/META/BRK-B/JPM/AVGO/TSLA, 각 NI/매출 2패널, 실제1연도+향후2연도 | NI는 EPS 성장 연결 근사, 매출은 직접 애널리스트 컨센서스 |
| 연간·분기 상세 | 기업명/코드 검색·선택, 연간/분기 전환, NI/OP/매출 3패널과 원통화 표 | 공급자 최신 수정 연간 최대4개·개별 분기 최대8개. 누적·TTM 아님 |

모든 막대는 실제 부호와0축을 보존한다. 미산출은 `—`이며0/평평한 추정으로 채우지 않는다. 원본의 한국 카드에는 최신1추정 연도만 있었으나 현재 로컬에 확보한 다음 연도도 함께 표시했다. 색·크기는 팀 스타일이다. 가격은 기준일까지의 비조정 종가, 목표가·PER·시총은 재무 조회 시점의 참고값이다. 목표가 대비는 그 두 시점의 산술 비교이며 기대수익률이 아니다.

## 회계연도와 NI 근사

원본의 미국/글로벌 NI 미래 금액은 직접 NI 컨센서스가 아니라 **최근 실제 NI에 EPS 성장률을 적용한 근사**다. 원본의 모든 기업에 고정한 달력연도 표기는 그대로 옮기지 않는다. 수집 시 이미 받은 Yahoo `earningsTrend`에서 `period/endDate`만 추가 보존한다. 이 메타데이터 때문에 추가 네트워크 조회를 하지 않는다. 내부 yfinance 필드가 없어지면 기간을 미확보로 처리한다.

- FY1 NI 근사 = 최근 실제 NI × (`0y.avg` / `0y.yearAgoEps`).
- FY2 NI 근사 = FY1 NI 근사 × (`+1y.avg` / `+1y.yearAgoEps`).
- 매출은 `revenue_estimate.avg`를 직접 사용한다.
- 추정 종료일−1년과 이전 회계기간말 차이는 최대8일을 허용한다. 52/53주 결산을 위한 팀 기준이다.
- EPS 통화와 재무 통화가 일치해야 NI를 연결한다. 매출도 해당 통화가 확인되어야 한다. ADR EPS가 다른 통화라면 임의 환산하지 않는다.
- 첫 추정의 전년 매출과 실제 연간 매출, FY2의 전년 EPS와 FY1 EPS의 차이가5%를 넘으면 NI 연결을 중단한다. 팀의 보수적 불일치 탐지 기준으로 회계감사 기준이 아니다. 예를 들어 보험·투자손익 포함 여부로 매출 정의가 다른 Berkshire는 직접 매출 추정만 남을 수 있다.
- 이전 NI 또는 전년 EPS가0/음수이거나 EPS가 없으면 일반 성장 연결을 하지 않는다. 양의 기준에서 예상 EPS가 음수로 바뀌면 그 음수 NI를 그대로 표시한다.
- GAAP/조정 EPS 차이, 주식수 변화, 일회성 손익을 복원하지 않는다. 따라서 NI 근사를 직접 순이익 컨센서스·매매 신호로 명명하지 않는다. 원본의 근거 불명확한 ‘보수적 보정’ 계수는 사용하지 않는다.

NVIDIA의 FY2026 실제 결산일은 [SEC 10-K의2026-01-25](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000021/nvda-20260125.htm)이다. 공급자는 월말 `2026-01-31`로 표준화해 반환한다. 화면의 날짜는 **제공처 회계기간 표기**로 명시하며 발표일·법적 결산일이라고 부르지 않는다. Microsoft의 FY2026은 [2026-06-30](https://www.sec.gov/Archives/edgar/data/789019/000119312526323660/msft-20260630.htm) 종료로 확인했다. 이 두 기업 외 모든 재무제표의 SEC 날짜를 직접 대조했다는 의미는 아니다.

## 국내 자료와 환산

국내 실제 순이익은 `NetIncomeCommonStockholders`, OP는 `OperatingIncome`이다. QuantiWise 미래 순이익은 `E122710.M` 지배 NI, OP는 `E121500.M`, 매출은 `E121000.M`이다. `AS` 기간별로 가격 기준일 이하의 가장 최근 관측을 골라 원자료 기준일을 공개한다. 기존2024AS/2025AS 전망 관측을 연도만 보고 실제 실적으로 바꾸지 않는다.

QuantiWise 원단위는 `KRW 100mn`(억원)이어야 하며 **억원÷10,000=조원**이다. 현재 개발 표본의 추정 원자료 기준일은2026-08-07로 가격/재무 조회일과 다르다. 기존 로컬 데이터베이스를 주간 재수입하므로 원본 DB에 새 관측이 없으면 날짜도 그대로 남는다. FnGuide 사이트의 세션 숫자를 복제하지 않으며 증권사별 보고서 URL은 아직 확보하지 못했다.

글로벌 NI는 기준일까지의 최근 환율(최대7일 경과)을 사용한다. KRW/JPY/CNY/INR/TWD/CAD는 각 `XXX=X`(현지 통화/USD)로 나누고 EUR/GBP는 `EURUSD=X`/`GBPUSD=X`로 곱한다. 회계기간 평균 환율이 아닌 **현재 환율 환산 비교**다. 환율 부호·날짜·통화를 검증하고 미확보 기업은 표본에서 제외한다. USD bn은10억 달러다.

## 갱신과 검증

재무/추정은 기존 주간 수집, 가격·환율은 평일08/18시 갱신에 포함한다. 새5개 환율은 공통 가격 카탈로그에 등록했으며 일회성 개발 입력이 아니다. 원자료는 PC의 부모 빈티지+변경분으로 보존하고 작은 파생 결과만 게시한다. 미래 회계기간을 추정으로 표시하는 것과 과거 백테스트에서 미래 데이터를 쓰는 것은 구분하며 이 화면은 최신 스냅샷이다. 가격 기준일 이후 실제 재무기간은 제외하지만 실제 발표 당시 자료 빈티지/PIT를 보장하지 않는다.

Python fixture는 회계기간·52주 결산·연결식·음수/미확보·매출 기준 불일치·환율 방향/신선도·국내 단위/관측일·수집 메타데이터를 검사한다. JavaScript fixture는 겹침막대/음수0축·기업 검색·연간/분기 콜백·출처 이스케이프를 검사한다. 대표 SVG를 오프라인 래스터로 확인한다. 브라우저 전체 동작·픽셀 동일성 검사가 아니다.
