# 지수 ML 구현 계약

2026-09-09 구현. 원본 사이트를 다시 조회하지 않고 보존한 설명·JSON 평가표·차트 구조를 대조했다. 원자료는 PC에서 수집하며 원본의 예측 수치·모형 가중치를 사용하지 않는다.

## 입력과 변수 선택

완료된 월의 KOSPI/Nasdaq/S&P500 각각 다음1개월·3개월 누적 수익률을 예측한다. 후보142개는 거시 수준/YoY/3개월 변화, 지수·상대수익률, 금리·신용·환율·원자재, 변동성 기간구조·꼬리위험, 집중도, EPU/GPR, 한국 수출·OECD CLI·증시 유동성 등이다. 현재 원점은2026-08말이다.

한국 투자자예탁금과 신용융자잔고는 ECOS `901Y056/M/S23A`, `901Y056/M/S23E`의 원 단위 자료이며 2004-01~2026-08 각272개월을 확보했다. 입력은 YoY와 그3개월 변화로 바꾼다. 거시는 가격 월 인덱스에 정렬한 뒤2개월 시차를 적용한다. 최신 수정값에 시차를 준 결과이며 발표 당시 자료를 복원한 PIT 성과가 아니다.

각 학습창에서 관측이 max(36개월,70%) 이상이고 변동이 있는 변수를 후보로 삼는다. 강제 변수도24개월 이상과 변동성이 있어야 한다. 결측 대체 중앙값·표준화 통계는 그 학습창 안에서 구한다. 변수 자체가 없는 경우0으로 만들지 않는다. 위험 z는60개월/최소36개월이며 평탄한 관측 시계열만0으로 처리한다.

RandomForest와 셔플 shadow를12번 적합하여 shadow 최대 중요도 초과 횟수 상위22개를 고른다. 동점은 평균 중요도, 변수명 순으로 고른다. 여기에 가용 위험/한국 강제 입력을 합친다. 원본의 설명은 엄격한 Boruta 유의성 확정검정과 다르므로 차트도 'Shadow 초과 횟수'로 표시한다. 미국 패널은 S&P500 대표이고 Nasdaq은 별도 선택한다. 강제 포함·미확보·최신 선택 목록을 남긴다.

## 모형과 시간 정렬

원본 설명문은10종을 열거하지만 실제 저장 평가표와 차트에는 Transformer가 추가로 있다. 팀 구현은11종+평균/중앙값 앙상블, 총13개를 비교한다. 공개되지 않은 설정은 아래 팀 설정이다.

| 모형 | 설정 |
|---|---|
| Lasso / ElasticNet | alpha .15 / .2, EN l1_ratio .3, 표준화 |
| BayesianRidge | 라이브러리 기본 사전·표준화 |
| KNN | 거리 가중12이웃·표준화 |
| RandomForest / ExtraTrees | 64트리, 깊이4, 최소 잎8 |
| XGBoost | 64트리, 깊이3, 학습률.04, child10, lambda5 |
| LightGBM | 64트리, 깊이3, 7잎, 최소 잎15, 학습률.04, lambda3 |
| MLP | 32/16노드, alpha1, Adam .005, 최대250회, 입력/타깃 표준화 |
| LSTM | 과거12개월, 은닉8, 60회, Adam .005, weight_decay .02 |
| Transformer | 과거12개월, d_model16, 2heads, 1층, FF32, 위치 인코딩, dropout0, 60회, Adam .003, weight_decay .03 |
| Ens-Mean / Ens-Median | 같은 원점의11종 출력 평균/중앙값 |

최소96개월의 만기 종료 라벨로 시작한다. 일반9종·변수 선택은6개월, LSTM/Transformer는12개월마다 다시 적합한다. 시퀀스는 원점 이전12개월만 사용하며 미래 토큰이 없다. 신경망은 타깃도 학습창에서 표준화한다. MLP 수렴 경고는 숨기지 않고 최신 학습 진단에 표시한다. CPU1코어·고정 seed로 계산한다.

1M은164개, 3M은162개 원점 예측을 보존했다. 각 원점에서 그때까지 타깃이 만료된 최근120개 이내 평가로 방향 적중률 최대, 동점이면 RMSE 최소 모형을 선택한다. 만료 평가24개 전에는 평균 앙상블이다. 전체 OOS 최고 모형을 과거 전 구간에 사후 적용하지 않는다. 3M 예측은 반드시3개월이 지난 뒤 학습·선택·보정에 들어간다.

선택 모형의 과거 만기 종료 잔차 최대120개·최소24개로 68%/90% 경험적 구간을 구한다. P상승은 Φ(예측/잔차표준편차)이며 보정된 실제 적중 빈도를 보장하지 않는다. 52%초과/48%미만과 score MoM·과거 중앙값으로5단계 신호를 구성한다. 위/아래 강도는 팀 규칙이며 수익 보장이 아니다.

## 화면 구조

- 전망 요약:6타깃 표, 컴포짓1+지수3+시장별ML3의7계열 단일 z축, 시계열 사분위 음영, 0선, 아래 L=-2~3의6개 상관 막대.
- 개별6타깃: 장기 ML/지수 단일 z축, 최근36개월 score좌축/지수우축·월별점·50선·사분위 음영, 최근24개월 원점/타깃/모형/score MoM·YoY/4분면/예측·실현·적중/가격·수익률/5단계 신호 표. 만기 전 최신 예측은 표와 상단에 별도로 표시한다.
- 수익률 예측선·실현막대·적중점·68/90% 구간, 1M 방향전략과 보유 누적선도 유지한다. 방향전략은 월말 가정 체결·편도5bp로, 실제 배포 시점과 주문 체결을 복원한 성과가 아니다.
- 모형 비교: KOSPI/Nasdaq/S&P500 3패널, 각13모형×1M/3M 막대와50%선. 최근120개 채점 결과 표와36개 적중 스트립.
- 변수 선택: US/KR 2패널,0~12회 가로축, 선택 변수별 가로막대, 강제 변수 별표. 최신 입력·수렴·자료 부족·학습원점 진단.
- SHAP: US/KR LightGBM의 중요15변수 beeswarm,0선·양/음 기여도%p·변수별색·색척도. 별도 전체 가용 라벨 적합의 최근120개 학습월이다. 당시 선택 모형의 OOS 기여 또는 인과 효과가 아니다. native TreeSHAP 합계가 모델 출력과1e-6 이내 일치하는지 검사한다.

시각화의 z와 사분위 음영은 표시기간 정규화이며 모델 입력 또는 역사적인 실시간 임계가 아니다. 컴포짓 상관의 비교 대상은3지수 동일 비중 월수익률이며 L>0이면 선행이다. 탐색적 상관으로 표시하며 예측 검정으로 주장하지 않는다.

## 자료 한계와 갱신

미확보 입력은 CAPE/ERP, SF Fed 뉴스감성, 글로벌 월간 EPU, 역사 외국인 수급, VIX9D 등이다. [FRED HY OAS 안내](https://fred.stlouisfed.org/series/BAMLH0A0HYM2)는2026-04 이후 공개 이력이 최근3년으로 제한됨을 밝힌다. 현재2개월 거시 시차 뒤36개월 z 준비 기간이 부족하여 HY·HY/IG z와 이를 모두 요구하는 위험 합성 입력은 미산출이다. 대용 변수로 조용히 바꾸지 않는다.

정기 갱신은7일·월 변경·구현 버전 변경 시 계산한다. 월별 입력/코드 해시가 같으면 각 타깃의 압축 결과를 재사용하고, 바뀌면 과거 원점을 전체 재계산한다. 변경된 입력에 증분 학습만 적용한다고 주장하지 않는다. 학습 횟수는 캐시를 사용하며 외부 ML 서비스에 데이터를 보내지 않는다. 원자료와 학습 캐시는 PC에 보관하며 누적 용량 검사나 용량 상한은 적용하지 않는다.

검사: 미래 입력/가격 변경 전 원점 예측 불변성, 강제 입력 부재,3M 만기,13모형 앙상블, Transformer 시퀀스, 잔차 보정/과거 선택, SHAP 가산성, 전체 세부탭 렌더·전환과 실제 SVG의 패널/점/축/구간/막대 수. 브라우저 QA나 원본 수치 동등성을 완료한 것은 아니다.
