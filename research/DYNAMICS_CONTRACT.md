# 시장 변동성 · 계산·기간·비용 계약

보존한 공개 설명과18대상 데이터, 표면·위상·위험·성과 렌더러를 오프라인 대조했다. 기존의60개월 위상 궤적을 **36개월**로 수정하고, 위험≥65의 음영과 표면 시간 재생/정지·관측일, 비용 선택·월별/일별 원장을 추가했다. 추가 원자료·AI모델 호출 없이 기존 가격 빈티지를 사용한다.

## 표본과 계산

S&P500/KOSPI/NASDAQ 지수3개, 미국10·한국5기업을 기존 종목코드로 계산한다. 수정종가와 실제 시장 달력을 먼저 정렬한 뒤 수익률/시차를 계산한다. 결측 가격을 전일값으로 채우거나 일수익 계산 전에 날짜를 삭제하지 않는다. 상장 전 날짜는 넣지 않는다. 지수는 가격지수의 가상 노출 비교이며 실제 선물/ETF 총수익률이 아니다.

| 관측 | 계산 |
|---|---|
| 일수익 r | P(t)/P(t−1)−1, 결측시 미산출 |
| β | 21일 평균(r)/모집단 sd(r) × √252 |
| α | β(t)−β(t−5) |
| ∇τ | 21일 sd(절대값(r(t)−r(t−1))) / mean(절대값(r)) |
| z | 처음부터 현재까지 확장창 평균·모집단 표준편차, 최소252개 유효값 |
| 취약성 | 100×logistic(z∇τ−0.5zβ−0.5zα) |
| 목표 노출 | min(1.5,0.15/연변동성)×(1−0.6×취약성/100) |

분모·확장창 분산0은 미산출이며 안정 점수0으로 확정하지 않는다. 계산 전에 기준일 이후를 제거한다. 21일/5일/가중치/노출식은 공개 설명을 따른다. 확장창 최소252·모집단 표준편차·0분산 처리·현재 정정가격은 명시적 팀 계약이며 비공개 코드와 수치 동등성을 주장하지 않는다.

∇τ는 경험적 불안정성 지표이고 위험점수는 확률이 아니다. 상태는 <32 강건,32~<45 안정,45~<57 중립,57~<70 경계,≥70 고위험이다. 원본 렌더러의 추이 음영선65와 상태 분류70의 차이를 유지한다.

## 네 가지 차트

- 표면: 최근60달력개월 × [5,10,20,40,60,90,120,180]일 연환산 변동성(%). 실제 월내 마지막 가격 관측일과 각 창의 값. 네 꼭짓점이 가용한 면만 그린다. 결측을 높이0 또는 ‘현재’ 마커로 표시하지 않는다. 회전/확대/시점 이동·재생/정지·초기화를 제공하고 화면 이탈 또는 숨김 시 타이머를 정리한다.
- 위상: 최근36달력개월의 월별 β×∇τ 궤적, 취약성 색과 최신 큰 점. 누락 월을 만들지 않는다.
- 위험: 최근60달력개월 취약성0~100(좌)과 가격지수(우),65선·해당 관측의 세로 음영. 가격지수는 최대144개월 표시 이력의 첫 실제 유효 관측=100으로 정규화하며 실제 종가는 별도 원장에 남긴다.
- 성과: 동일 평가 구간에서 시작100의 모델/단순보유2계열. 월별 마지막 실제 평가일과 초기100을 표시한다. 비용 시나리오를 바꿔도 두 계열·CAGR/변동성/Sharpe/MDD·평가일·원장이 함께 바뀐다.

월말이 휴일이거나 현재월이 진행 중이어도 날짜를 가상 월말로 늘리지 않는다. 준비 이력이 짧거나 결측 월이 있으면144/60/36보다 적은 관측을 표시한다. 기존 지수·종목18개 목록을 유지한다. 최근 유효 신호7일 초과 또는 준비 부족은 가용하지 않다.

## 평가와 거래·차입비용

신호는 매일 종가에 계산하고 **전일 신호를 당일 수익률에 한 번만 적용**한다. 현재 종가 신호로 당일 수익을 얻지 않는다. 가격/신호가 없는 날을 현금수익0으로 대체하지 않는다. 모든 비용 시나리오는 **마지막 결측 이후 연속 유효 구간**을 같은 초기자산100에서 비교한다. 그러므로 결측이 있는 한국 종목의 평가기간은 전체 가격 이력보다 짧을 수 있다. 이는 현재 선택된 평가 구간이고 역사 실시간 운용 성과가 아니다.

전일 장 종료 후 보유비중을 w, 오늘 적용하는 목표노출을 h라고 할 때:

- 회전율=|h−w|. w는 직전 자산 수익률과 비용 후 자산가치로 변화한 보유비중이다.
- 일별 거래비용률=회전율×편도bp/10000.
- 일별 차입비용률=max(h−1,0)×차입연율/252.
- 순수익률=h×자산수익률−거래비용률−차입비용률.
- 다음 보유비중=h×(1+자산수익률)/(1+순수익률).

최초 포지션 진입비용을 포함한다. Buy & Hold도 최초 매수비용을 차감하며 그 뒤 매매하지 않는다. 현금이자·세금·시장충격·실제 대차/차입·펀딩·분할매매·실제 체결가격은 미반영이다. 차입은 일초과노출에 대한 단순 가정이다. 자본이 소진되면 음수 순자산을 재투자하지 않고 평가를 중단한다.

| 선택 | 편도 거래비용 | 차입연율 |
|---|---:|---:|
| 원형 비교 | 0bp | 0% |
| 비용5 | 5bp | 0% |
| 차입3 | 5bp | 3% |
| 차입5 | 10bp | 5% |

이 값들은 비교를 위한 팀 가정이며 실제 비용 추정이나 사용자의 차입조건이 아니다. 노출은0~1.5 범위의 보유 가정이다. 공개 원형의 비용0 비교도 유지한다. 누적 회전율·비용률 합은 일별 비율의 합이며 복리 성과 차이와 다르다.

CAGR는 관측수/252년으로 연율화한다. 연변동성은 일별 순수익 표본표준편차×√252, Sharpe의 무위험수익은0, MDD는 초기100을 포함한다. 1년 미만 평가에도 계산값은 연율화되므로 관측수·기간과 함께 읽는다.

## 원장과 실행

표시 이력(최대144개월)의 β/α/∇τ/취약성/노출/가격지수, 최근252시장일의 원수익·z·신호, 비용별 최근252평가일의 신호일·적용일·보유/목표비중·회전율·비용·순수익·자산지수를 제공한다. 선택한 비용 원장은 UTF-8 BOM CSV로 로컬 저장한다. 원자료와 전체 일별 중간계산은 PC에 두고 공개에는 파생 관측을 제공한다.

기존 `market_modules.dynamics` → `dynamics_model.build`와 평일08/18 전체 빌드에 연결된다. `test_dynamics_model.py`는 수식·미래불변·결측 시차·분산0·전일 신호·드리프트·최초비용·차입비·자본소진·실제 월일을 검사한다. `dynamics_validation.py`는 게시값과 원장·기간·비용·차트의 일관성을 검사한다. 브라우저에서는18대상×4비용, 표면·위상·위험 음영, 재생정지/이탈정리와 CSV를 검증한다.

남은 범위: 공개되지 않은 최소표본·정정가격 빈티지와 수치 동등성, 결측 전 전체기간의 신뢰할 수 있는 원자료 보완, 실제 체결/펀딩/세금과 PIT 검증. 원본의 수식·전체 화면 묶음 캡처와 선택 종목 링크 공유는 별도 구현 대상이며 현재 공통 차트 내보내기와 데이터 CSV/JSON을 제공한다.
