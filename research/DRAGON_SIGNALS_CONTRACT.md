# DRAGONGLASS 지금 주목·트리거 계약

보존한 `dragonglass.js`의 watchHTML/insightFeedHTML/themeRadarHTML/alertHTML 구조와 현재 계산 스냅샷을 연결한다. 원본 웹사이트 추가 요청이나 모델 호출 없이 Python에서 재생성한다. 평일08/18 build_all의 ASK 계산 이후 실행하며 ASK 모듈 요약도 새 상태로 갱신한다.

## 관측과 미확보 항목

트리거 공개 규칙은 구루3, 주도주2, 발굴2, 관심급등2, 리서치 양의 기대수익2, 뉴스8건1, 감성양수1이다. 이번에 연결한 것은 주도주와 발굴 두 종류이며 같은 종목·같은 모듈은 중복 합산하지 않는다. 기업별 전체 뉴스·관심 시계열/감성,13F,수치 투자뷰는 아직 없으므로 전체점수는 null이다. 미확보를 관측0으로 확정하지 않는다. 두 기술 기반 신호는 독립 확률이나 검증된 투자 확신도가 아니다.

주도주는 공식 한국 대형주·미국 IVV 표본의 RS 상위15씩이다. 발굴은 현재 discovery 화면에 실제 선별된 기업 중 Entity360과 가격일이 같은 종목만 결합한다. 기준일 이후 또는7일을 초과한 가격일, Entity360 부재, 서로 다른 가격일은 제외 원장에 남긴다. OHLC 불일치로 발굴의 최종 기술 관측일이 이전일이면 최신 종가 Entity360과 합치지 않는다. 다른 날짜의 모듈 스냅샷을 섞으면 생성 오류로 중단한다.

원본 watch는 `1.1×live + 0.5×min(abs(기대수익),80) + 2.2×관계수 + 6×문서수`로 상위15를 정한다. live의 산식과 비공개 기대수익은 확보되지 않았다. 따라서 전체 순위 점수를 재현했다고 표시하지 않는다. 화면은 확인된 신호 합을 먼저 정렬하고, 동점이면 공개 관계수×2.2+고유 공식문서수×6, 마지막은 객체ID 순이다. 관측 가능한 부분 순위이며 원본 전체 순위와 다르다. 전체점수/live/기대수익 필드는 null을 유지한다. 관계수는 사업·공급·경쟁·가격상관 모두를 포함하고 공급사/고객은 supplies 관계만 사용한다. 고유 공식 문서는 리서치 카탈로그의 URL 중복 제거 결과를 사용한다.

## 화면 구조

지금 주목은 순풍/경계/경계값 3열의 모듈 근거, 매크로·지정학 제목 레이더, 상위6개 테마의 관측·확인할 조건·사업근거,3개월 크로스에셋 상위/하위 두 패널,15종목 카드로 구성한다. 테마의 순위는 기존 ASK10개 사업목록의3개월 수익률 순위이며 전체 테마 자금유입이나 예상수익이 아니다. 레이더는 최근7달력일(기준일 포함)의 보존RSS 표본을 주제별로 묶는다. 기사는 주제에 중복될 수 있고 전체 언론량·감성으로 해석하지 않는다. 매크로 방향과 원자료 관측일은 ASK의 기존 공개 임계값을 그대로 사용한다.

트리거는7개 공개 규칙의 연결상태·가중치,2종 이상 동시관측 최대16기업,최근 위성촬영8건과 촬영 장면 원문을 제공한다. 촬영일과 재조회 시각/새 촬영 감지는 다르다. 현재 로그는 기존 위성 스냅샷의 촬영일 목록이며13F/임상모집 관측과 신규 이벤트 감지는 미연결이다. 기업 카드는 Entity360,시설카드는 해당 시설상세,신호칩은 RS/발굴,원문은 실제 근거로 이동한다. 시장/검색은 표시된 상위목록 안에서 필터링한다.

## 남은 원본 차이

전체255객체/581관계와 모든 근거문서,13F·기업뉴스·관심급등·감성·비공개투자뷰,원본live산식·전체종합순위,임상모집 및 신규관측 변화로그가 필요하다. 자동 생성 투자 아이디어/원본 LLM 해석과 현재 규칙 기반 관측 설명을 동일한 구현으로 취급하지 않는다. 현재 변화는 화면 구조와 확보한 신호의 연결이며 전체목표 완료가 아니다.
