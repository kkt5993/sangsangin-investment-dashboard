# 모멘텀 (섹터·절대·초과수익)

국가·섹터·팩터의 절대 수익률과 벤치마크 초과수익으로 로테이션을 확인한다.

## 구현 순서

1. 같은 날짜의 조정가격 패널을 만들고 기간별 절대 수익과 벤치 초과수익을 산출한다.
2. 현재 table의 그룹·열·comment를 데이터 계약으로 사용하고 bars/heatmaps를 생성한다.
3. 섹터별 3M·6M 차트 32개의 기간·축·주석을 보존한다.

## 검증 과제

- 각 그룹의 벤치마크 고정
- 통화·수익률 기준·배당 처리
- 서로 다른 기간의 강도를 직접 혼합하지 않도록 라벨 확인

## 확인이 더 필요한 부분

절대강세 합성 규칙과 데이터 오류 처리의 전체 코드가 필요하다.
