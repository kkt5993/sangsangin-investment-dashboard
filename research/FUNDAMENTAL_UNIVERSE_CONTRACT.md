# 재무 유니버스 수집·재개

`pipeline.acquire fundamentals`의 기본 경로는 `fundamental_universe`와 기존 `company_fundamentals` 수집기를 사용한다. 개별 종목을 명시하는 내부 수집 함수는 기존 원자료 획득 경로를 유지한다.

## 대상과 출처

현재 빈티지에서 부모 체인을 따라 각 구성자료의 최신 파일을 선택한다. `us_largecap`, `us100`, `kr_largecap`, `kr_screen`, `kospi200`의 정규화된 `members`와 기존 연구 종목·전략 지원 종목을 합친다. OEF 원문 CSV를 JSON으로 다시 읽지 않는다. 같은 기업이 여러 지수에 속해도 한 번만 수집하며, 정렬된 종목 목록·소속별 근거·구성자료 날짜·파일 해시를 로컬 `fundamental_universe/manifest.json.gz`에 보존한다.

IVV/OEF 공시 표본·KRX 구성·Naver 시총 화면은 서로 다른 출처다. 이를 전부 공식 지수 구성 또는 역사 구성종목이라고 표현하지 않는다. 미식별 관계 기업에 추정 티커를 붙이지 않는다. `--limit`은 명시적인 실행 표본 선택이며 저장량이나 전체 유니버스의 상한이 아니다.

## 정상 자료와 실패 처리

실제 연간 또는 분기 손익 항목 및 재무 통화가 있는 자료만 정상 캐시로 인정한다. 정상 자료는 종목별 7일 동안 재사용한다. 빈 응답·통화 미확인·실패·기존 정상값을 대체할 수 없는 부분 응답은 미확보/이전 자료 보존으로 기록한다. 실패 관측을 정상 원자료 폴더에 덮어쓰지 않는다. 시도별 원응답은 저장소 밖 `company_financial/attempts/`에 남는다.

사용 가능한 일부 손익 자료와 오류가 함께 있는 캐시는 재사용할 수 있으나 `partial` 상태를 유지한다. 긴 배치에서도 기업별 실제 조회 시각을 사용하고, 배치 시작 후 한 시간이 지났다는 이유만으로 새 응답을 미래 자료로 오인하지 않는다.

별도 `fundamental_universe/collection.json.gz`를 사용하므로 기업 뉴스의 재무·실적 달력 수집 원장을 덮어쓰지 않는다. 이 경로는 재무만 수집하고 달력은 기존 수집 경로가 담당한다. 제공처 요청 제한은 배치를 중단하고 남은 종목을 보류하며, 한 시간 안의 재실행은 외부 요청 없이 반환한다. 유예 후 완료 캐시를 재사용하고 나머지를 재시도한다.

기존 평일08/18 갱신에서 이 경로를 실행한다. 상위 재무 폴더 수정일로 전체를 건너뛰는 대신 종목별 신선도와 실패 유예를 검사하므로 신규 구성종목도 감지한다. 새 예약·유료 API·메시지 발송을 추가하지 않는다.

## 검증 범위

부모 구성 상속·자식 구성 교체·중복 제거·CSV 정규화 결과 재사용, 정상 재무 캐시와 달력 분리, 미확보/부분 응답 보존, 요청 제한 중단·유예·재개를 테스트한다. 수집 대상 등록은 해당 기업의 재무 확보나 기업 상세·시장 달력·사업관계 전체 검증 완료를 뜻하지 않는다. 실제 확보 수와 미확보 수는 실행 원장을 기준으로 별도로 보고한다.

2026-09-13 실제 검증: 가격 기준일2026-09-10의 구성자료 합집합945종목 중 최근 정상 재무215종목을 재사용할 수 있었다. 미확보 한국3개(000080.KS/000100.KS/000120.KS)·미국3개(A/ABBV/ABT)의 재무를 추가 수집해221종목으로 확대했다. 연간·분기 손익162값의 원자료 대조와 즉시 재실행0조회 확인을 마쳤다. 724종목은 여전히 미확보이며, 전체945종목 수집 완료를 의미하지 않는다. 별도 로컬 빈티지20260913T112310Z와 `runtime/fundamental-universe-pilot-result.json`에 보존했고 공개 스냅샷·배포에는 아직 반영하지 않았다.
