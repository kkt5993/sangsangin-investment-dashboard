## 다음 작업 순서

1. RS 미확인 페어를 원본의 실제 종목코드 또는 원천 데이터 계열로 확정한다. 원본 그래프의 숫자를 역추적해 가격을 만들어 넣지 않는다. z 창 길이·최소 관측수·ddof·모멘텀 누적산식을 확인하고 기준일별 회귀 검증을 추가한다.
2. KR/US 대형주와 오닐 순위에 필요한 **전체 유니버스**를 정한다. 기존 로컬 DB에 종목·수정가격이 있지만 지수 편입 이력과 공개 게시 범위까지 동일하다고 가정하지 않는다.
3. ETF 큐레이션과 멀티에셋을 가격 엔진에 추가한다. 가격만으로 자금흐름을 추정해서 실제 펀드 플로우로 표시하지 않는다.
4. 국면→실적/성장→위험→전략/모델→관계/기록 탭 순서로 진행한다. 각 탭에 [차트 대응표](CHART_PARITY.md), 데이터 계약, 숫자 검증을 함께 추가한다.

## 완료 기준

- 모든 하위 그룹과 차트가 데이터·계산식까지 연결됨.
- 원본의 축·기간·시리즈·벤치마크·구간 표식·패널 구성을 대조함.
- 기준일·단위·결측·수정·휴장·소급 오류를 검증함.
- 비공개 설정으로 재현하지 못한 부분은 해당 탭의 완료를 막는 항목으로 남김.
- 코드·문서·작은 파생 결과만 GitHub, 원자료·모형 산출은 PC. 큰 저장 공간이 필요하면 먼저 사용자에게 문의.
