# 가격 기반 탭의 계산 계약

버전 `prices-v1` · 작성 2026-09-09 · RS와 모멘텀에 적용.

## 확인된 것과 선택한 것

[학습 원본](https://aragorn-investium.pages.dev/#glance)의 공개 설명·차트 주석·2026-09-06 RS 스냅샷을 이미 저장한 로컬 파일로만 대조했다. 원본 서버 코드는 없다. 차트를 다시 그리는 코드와 가격 수집·계산 코드는 팀이 작성했다. 원본의 이미지나 표 숫자를 결과로 재게시하지 않는다.

| 항목 | 이 구현의 계약 | 근거 / 한계 |
|---|---|---|
| RS 기초값 | 두 종목 3개월 기간수익률의 차이, %p | 원본에 명시됨. 가격비의 z-score와 다름 |
| 기간 | 1W=5, 1M=21, 3M=63, 6M=126, 1Y=252개 공통 거래 관측치 | 팀의 명시적 설정. 3M=63은 원본 같은 기준일 수익률 대조로 지지됨 |
| z-score | 위 스프레드의 1,260개 rolling 평균·표준편차, ddof=0 | 원본은 5Y라고만 설명. 정확한 창·최소 관측수·ddof 미공개 |
| 준비 구간 | 63일 수익률 + 완전한 1,260개 스프레드 관측치 필요 | IPO 이전이나 준비 구간을 다른 계열로 잇지 않음 |
| Δz 1W | 현재 z − 5개 공통 관측치 전 z | 주간 변화. 표 단위 σ |
| YTD | 같은 계열의 직전 연도 마지막 종가 대비 | 당해 첫 거래일을 분모로 쓰지 않음 |
| 가격 필드 | KR ETF: Yahoo Adj Close. US ETF: Yahoo Close. 지수·BTC: Close | 원본 같은 날짜 대조에서 KR 배당 조정, US 배당 미재투자와 부합. 혼합 가격 기준을 명시 |
| 휴장·결측 | 두 종목의 날짜 교집합, 전방 채우기 없음 | 미래 가격을 소급 사용하지 않음 |
| 기준일 | 완료된 날짜만 수집. 결과별 마지막 공통 거래일 표시 | 요청 날짜와 실제 가격일을 구분 |
| 전체 자산 순위 | 32개 국가·팩터·자산 모두 가격이 있는 가장 최근 날짜 | 첫 버전은 2026-09-04. 일부 자산이 오래된 경우 숨기지 않음 |
| 기간별 자산 수익률 | SPY와 공통 거래일로 계산. 국가 ETF·BTC는 USD | BTC도 이 비교에서는 미국 시장 관측 간격을 따름. 현지 지수의 자국통화 성과가 아님 |
| 섹터 초과수익 곡선 | `100 × [(A_t/A_0)/(B_t/B_0) − 1]` | 3M·6M은 달력 월. 시작일 이전 마지막 공통 종가를 기준으로 0에서 출발. 원본의 누적 계산 상세는 미공개이므로 팀 가정 |
| 차트 기준선 | RS 선 차트 0·±1·±2, 순위 막대 0·±1·±2.58 | 원본의 차트/막대 기준 불일치를 그대로 구분 |
| 과열/과매도 | 선 차트에 맞춰 z≥2, z≤−2 | 원본 표의 구간 경계 전체는 확정 불가. 팀 선택 |
| 원자료 수정 | 날짜별 수집본과 SHA256 보존 | Yahoo가 사후 수정한 과거 데이터이며 과거 가용성/PIT를 보장하지 않음 |

수식은 `pipeline/analytics.py`, 종목은 `pipeline/universe.py`, 수집·저장은 `pipeline/collect.py`와 `pipeline/store.py`에 있다. [yfinance 공식 문서](https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html)의 조정 옵션·종료일 배타 규칙에 맞춰 명시적으로 요청한다. 원자료에는 종가·조정종가·배당·분할을 함께 보존한다.

## 원본 수치 대조

원본 RS 작성일 2026-09-06에 맞춰 로컬 가격을 절단해 검증했다. 일요일이므로 실제 가격일은 2026-09-04다. 최신 09-08 결과와 09-06 원본을 직접 비교하지 않았다. 대조 도구는 `scripts/compare_reference.py`이며 네트워크 없이 실행된다.

| 항목 | KR 12개 | US 17개 |
|---|---:|---:|
| 원본의 0.1%p 표시 정밀도에 부합한 스프레드 | 11/12 | 17/17 |
| 최대 스프레드 절대차 (%p) | 0.1368 | 0.0495 |
| z-score 평균 절대차 (σ) | 0.0252 | 0.0163 |
| z-score 최대 절대차 (σ) | 0.0898 | 0.0393 |

이것은 단일 시점의 진단이다. 원본 계산식과의 동등성 인증이 아니다. z 창 길이·데이터 수정·표준편차 설정을 더 확인해야 한다. 모멘텀 누적 곡선의 점별 동등성은 검증되지 않았다. 원본은 시계열 숫자 대신 PNG만 공개하여 같은 점들을 직접 비교할 수 없다.

## 주도주·대형주 순위

원본의 KR·US 대형주 전체 유니버스와 KOSPI200 주도주 사전 선별 기준이 없다. 몇 개 예시 종목만 가져와 시장 전체 순위로 표시하지 않는다. RS의 해당 패널·막대는 준비 상태를 표시한다.

`stock_ranking()`에는 명시적으로 주어진 종목 목록을 계산하는 함수를 구현했다. 3/6/9/12개월 누적수익 가중치 40/20/20/20과 동점 백분위를 사용하지만 **팀 가정이며 화면에는 연결하지 않았다**. 대상 목록, 가격 사용 범위, 가중치, 최소 관측수, 편입 기준일을 확정한 후 연결한다. 현재 보유한 다른 로컬 연구 DB의 종목 목록을 KOSPI200이라고 재명명하거나 유료 데이터를 자동 게시하지 않는다.
