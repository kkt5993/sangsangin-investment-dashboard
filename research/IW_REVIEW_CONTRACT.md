# IW 월말 복기와 주간 기록

보존한 원본 IW의29행은 독립 지표29개가 아니라 월말 복기15건과 주간 연대기14건이다. 팀 화면은 같은 구성을 자체 ML 원장과 관측값으로 생성한다. 원본의 논평·이미지를 재게시하지 않는다. 원본 본문과 표의 합계가 다른 경우도 있어 방향 일치 건수와 상세 표는 반드시 같은 계산 결과에서 생성한다.

## 월말 복기15건

완료된 최근15타깃 월을 사용한다. KOSPI·NASDAQ Composite·S&P500의1M 예측, 실현 수익률, 선택 모형, 예측 원점, 학습 라벨 종료일을 함께 표시한다. 예측과 실현의 부호가 같을 때 방향 일치다. 0은 별도 부호이고 결측은 미채점이다. 해당 월말까지의 마지막 가격을 표시하며7일 이상 오래된 값은 비운다.

예측은 현재 자료로 재생한 [팀 OOS 모델](ML_MODEL_CONTRACT.md) 결과다. 현재 수정 거시자료와 현재 구성종목을 사용하는 한계가 있으며 당시 실제 게시본이나 원본 작성자의 예측을 복원한 것이 아니다.

## 주간 연대기14건과 누적 보관

ISO 연도/주차로 식별한다. 지난주는 금요일, 이번주는 자료 기준일과 금요일 중 먼저인 날짜를 사용한다. 지수 수준·실제 가격일·5거래일/YTD 수익률,1M/3M 예측, VIX·미국10Y·NFCI·HY OAS와 관측일을 기록한다. 예측 원점이 기록일을 넘는 결과는 선택하지 않으며3M을 만기 전에 채점하지 않는다.

최초 생성한 과거13주는 현재 데이터로 재구성했다고 표시한다. 현재 주는 정기 갱신 때 바뀌며 최초 저장시각은 유지한다. 다음 주부터는 지난주 기록과 차트를 수정하지 않는다. 처음 기록 당시의 모형 기준일·데이터 빈티지·모형 SHA-256·방법 버전을 함께 남긴다. 이 보존은 과거 재구성을 실제 당시의 발행본으로 바꾸지 않는다.

전체 기록은 저장소 밖 해당 빈티지의 `iw_journal.json.gz`에 누적하고 화면에는 최근14주만 제공한다. 부모 빈티지에서 읽은 원장은 새 빈티지에 저장하며 기존 파일을 지우지 않는다. 알 수 없는 원장 버전이나 기록일을 거꾸로 돌리는 실행은 중단한다. 현재 주의 백업 값까지 포함해 수치와 그림을 같이 보존한다.

## 두 그림과 국면 규칙

첫 그림은 최근36완료월을 공통 가로축으로 경제·시장·위험3개 가로 띠에 표시한다. 원본의3단 범주 띠·월별 칸·범례 구조를 따른다. 월중은 확정 월말처럼 포함하지 않는다. 국면 탭에도 같은 그림과 규칙 표를 제공한다.

| 축 | 팀 계산 | 상태 |
|---|---|---|
| 경제 | 미국 산업생산 YoY와 CPI YoY의3개월 변화 부호 | 성장↑/물가↓골디락스,↑/↑리플레이션,↓/↑스태그플레이션,↓/↓침체압력 |
| 시장 | 위 성장 방향×미국10Y 월말 금리의3개월 변화 | 성장↑/금리↓봄,↑/↑여름,↓/↑가을,↓/↓겨울 |
| 위험 | VIX≥25, NFCI>0, HY OAS≥5%, M2 YoY<0, Sahm≥0.5 | 조건0~1개 위험선호,2개 중립,3개 이상 위험회피 |

성장·물가·M2·Sahm은 관측월보다2개월 늦게, NFCI는 관측일보다7일 늦게 이용한다. 이는 보수적인 정보 시차 규칙으로 정확한 발표시각 빈티지가 아니다. 성장 변화0은 상승 쪽, 물가 변화0은 상승 쪽, 금리 변화0은 하락 쪽에 포함한다. 위험 입력은5개 모두 있어야 분류하며 부족하면 회색 미산출로 둔다. 가용 자료를 정상 값으로 대체하지 않는다.

두 번째 그림은 팀 ML 컴포짓·3개 시장 예측·3개 지수의7계열이다. 선택한 기록의 마지막 완료월까지만 자르고 표시 구간으로 다시 표준화한다. 시각화값은 소수3자리이며 모형 계산을 반올림하는 것이 아니다. 최신 그림과 주간별 보존 그림을 선택할 수 있다. 과거 그림의 표준화·분위 구간에 이후 관측값을 사용하지 않는다.

## 검증과 남은 범위

Python 검사는 국면 임계값·필수 입력 결측·거시 시차·미래 관측 변경 영향·동일 원장의 일치 건수·예측 원점·지난주 보존·현재 주 갱신을 확인한다. 공개 데이터 검증기는15/14건·36월×3축·날짜·모형 해시를 검사한다. 실제 화면 콜백으로 기록 선택을 검사하고 대표 SVG를 브라우저 없이 래스터화한다.

팀 공용 DB, 작성자의 논평·개인 기록, 자동 LLM 글쓰기는 연결하지 않았다. 수치 기반 규칙 요약에 세계 사건이나 인과관계를 임의 생성하지 않는다. 사용자 판단과 PDF/이미지는 [브라우저 로컬 기록](LOCAL_RESEARCH.md)에 저장한다.
