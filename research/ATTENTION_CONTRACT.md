# 기업 문서 관심도 계약

보존된 원본에서 Wikipedia 관심도 값이 있던10기업(NVIDIA, AMD, TSMC, Intel, SK하이닉스, 삼성전자, Micron, ASML, Microsoft, Amazon)을 같은 범위로 연결한다. 원본의 값은 사용하지 않는다. `config/attention_pages.json`에 영문 문서 제목/page ID/Wikidata ID/정확한 티커를 고정했다. 최초 MediaWiki 제목 조회1회에서 문서·식별자를 검토했고 ASML Holding의 현재 정규 제목 ASML을 사용한다. 기업명 유사검색으로 종목을 자동 연결하지 않는다.

## 자료와 단위

[Wikimedia Analytics API](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/reference/page-views.html)의 `en.wikipedia.org/all-access/user` 일별 페이지 열람을 사용한다. UTC 날짜, 건수이며 user 분류는 자동화 트래픽을 제외하려는 제공처 분류다. 고유 사람·투자자 수나 매수 관심을 뜻하지 않는다. [제공처 정의](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/concepts/page-views.html)에 따라 리디렉션 제목 열람은 정규 문서에 자동 합산되지 않는다. 다른 언어·관련 문서·리디렉션까지의 전체 관심도는 아니다. 문서 개명 시의 전후 열람 연속성도 검증 전에는 보장하지 않는다.

초기60일을 받고 이후 기존 마지막 관측일부터6일을 되돌아가 겹치는7일 구간과 신규 일자를 조회한다. 제공처 정정을 반영하되 이전 빈티지는 보존한다. 초기 NVIDIA 진단 응답61일은 버리지 않고 재사용했다. API 응답의 project/title/access/agent/granularity/UTC일자/중복/정수·음수 여부를 검증한다. 요청 범위 밖의 날짜는 거부하며 결측을0으로 채우지 않는다. 응답에 빠진 재조회 구간의 기존 일자도 최신 정상 응답에서 결측으로 남긴다.

현재 UTC일에서2일 이전까지를 상한으로 쓰며 가격 기준일보다 늦은 날을 요청하지 않는다. 동일 완료일/설정의 성공 확인은24시간 캐시한다. 요청 간격1초, 실패 시1시간 백오프,401/403/429이면 같은 실행의 후속 요청을 중단한다. 실패는 이전 성공 열람/성공 시각을 유지하며 최신 오류를 따로 기록한다. 가격 계산과 같은08/18 refresh에 수집기를 연결했으며 브라우저는 이미 계산한 JSON만 읽는다. 저장 용량 검사·추가 AI 호출이 없다.

## 계산과 화면

실제 마지막 관측일부터 최근7달력일 합계와 바로 이전7달력일 합계를 비교한다.14일 모두 있어야 한다. `(최근7일/직전7일−1)×100`이며 직전 합계가0이면 변화는null이다. 원본의 정확한 비교 기간은 공개되지 않았으므로 이 기간은 팀 규칙이다. 원본 수치와의 동일성을 주장하지 않는다.

최근 관측일이 가격 기준일보다 늦지 않고3일 이내, 성공 수집 후72시간 이내, 최근 오류 없음,14일 완전한 경우에만 가용하다. 변화가+40% 이상이면 관심도 신호+2를 한 번 합산한다. 기술 신호는 동일한 가격일로 정렬하고 열람 신호는 별도 UTC 관측일과 실제 수집 시각을 표시한다. 현재 관측 모니터이며 과거 당시에 알 수 있었던 데이터 빈티지나 백테스트 입력으로 쓰지 않는다. 전체점수/live/기대수익은 계속null이며 기업 뉴스량·감성·정량뷰 미확보를0점으로 확정하지 않는다.

지금 주목에10문서 검색/카드,7일 합계·비교 기간·관측/성공/확인일과최근60일 선·전체보존일 원장을 제공한다. 가로축은 UTC일자, 세로축은0부터의 일별 열람 수, 누락일 사이에는 선을 잇지 않는다. 기업 상세에도 같은 근거가 표시된다. 신호칩/문서카드는 해당 기업 상세로 이동하며 원문은 실제 문서와 요청 통계 API를 가리킨다. 현황판 소스 카드에Wikimedia 수집일/실패를 반영한다.

최초 관측의 실제 최근7일은2026-09-03~09,비교기간은08-27~09-02다.10문서 전부 가용하지만+40% 이상은0문서다. 따라서 관심도 규칙이 연결되었다고 가짜 급등 기업을 만들지 않는다. 실제 이전4개 동시 신호는 유지된다.

남은 범위: 전체 기업 뉴스·감성/커뮤니티·추가 문서 및 언어·리디렉션 합산, 문서 개명 자동 검증, 원본 비공개 비교 기간/PIT 동등성. 이 기능은10기업 문서 열람이며 뉴스 전체 구현 완료가 아니다.

기업 상세 누락 보완: 기존701기업에 ASML 미국 상장 종목을 추가했다. 보존 가격이 없어서 기존 수집기로 ASML 1종목의3년 일봉752건을 확보하고 OHLC 범위·USD 호가를 확인한다. 공식 S&P500 구성원으로 편입하지 않으며 추가 관찰 종목으로 표시한다. 기업 상세702기업의 가격/수익률/SPY Beta/252일 상관 원장을 함께 계산하고 다음 정기 가격 갱신에도 포함한다. ASML의 미확보 재무·실적 예정일은 임의로 채우지 않는다.

ASML 최초 응답의 마지막 일봉은2026-09-09이며 가격 기준일2026-09-10으로 강제로 늘리지 않았다. 전체 종목 합집합252일 창에서 ASML의 유효 일 수익률은245개로 원장에 표시한다.
