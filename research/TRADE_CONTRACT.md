# 지구본 교역 데이터·화면 계약

국가 교역 하위 화면은 UN Comtrade의 **연간 상품 총수출(HS TOTAL, current USD)** 을 독립 수집해 표시한다. 기업 매출이나 실제 선박 항로를 표시하는 기능이 아니다. 밸류체인 유니버스의 기업별 공급·수출·물류 관계는 후속 구현 대상이다. SAURON은 [별도 계약](SAURON_CONTRACT.md)에 따라 연결했다.

## 보존 구조와 대응

보존 지구본은 밸류체인 유니버스와 SAURON의2개 상위 화면으로 구성된다. 전자는20그룹/53개 세부 업종,159개 배치/151개 고유 기업,96개 도시,3종 관계선과 기업 상세를 사용한다. 수출선 금액은 기업별 수출액이 아니라 국가 간 HS TOTAL 참고값이다. 기존 구현의 국가별 기업 표만으로 이 구조가 구현된 것으로 간주하지 않는다.

이번 국가 교역 화면은 같은 정사영 투영·구면 곡선·국가 대표 위치·수출 금액별 굵기·선택 상세 구조를 독립 구현한 보조 화면이다. 경위선10도, 드래그·키보드·경위도 조절, 휠/버튼 확대, 명시적 자동회전, 상대국 검색·정렬·상위10/20/전체, 방향 전환, 정확한 금액·분모·보고 시각을 제공한다. 반대쪽 반구를 가로질러 직선으로 연결하지 않으며 지평선에서 잘라 표시한다. 화살표는 항상 보고국에서 상대국으로 향한다. 지도를 못 읽어도 국가 선택·금액 표가 동작한다.

기업별151개 등록·도시·시총·사업 근거, 공급/물류 관계의 검증과3종 토글은 남아 있다. SAURON은 Cesium 3D 카메라, USGS 지진, CelesTrak 궤도 위성, 시설 레이어, 센서 스타일·검색/투어 등 별도 기능이다. 기존 DRAGONGLASS 위성 영상 관측과 동일한 기능으로 처리하지 않는다. 공개 subview 목록에서 밸류체인은 미연결, SAURON은 연결 범위와 남은 Google 실사3D를 구분한다.

## 원천과 통계지역

- [공식 API 설명](https://uncomtrade.org/docs/un-comtrade-api/), [공식 Python 클라이언트](https://github.com/uncomtrade/comtradeapicall)
- [보고지역 코드](https://comtradeapi.un.org/files/v1/app/reference/Reporters.json), [상대지역 코드](https://comtradeapi.un.org/files/v1/app/reference/partnerAreas.json)
- [관세 통계지역](https://uncomtrade.org/docs/reporter-country-codes-and-their-custom-areas/), [UN490 범위](https://uncomtrade.org/docs/taiwan-province-of-china-trade-data/)
- [500행 preview 범위와 제한](https://uncomtrade.org/docs/what-is-data-preview/)

`config/trade_areas.json`의45개 지역을 코드·ISO·공식 설명으로 대조한다. 일반 M49 숫자를 그대로 사용하지 않는다. 미국842는 푸에르토리코·미국령 버진아일랜드를 포함하며, 프랑스251·스위스757·노르웨이579에도 고유 통계지역 정의가 있다. 인도699, 영국826/GB를 사용한다. UN490은 Other Asia, nes이며 대만 외 아시아 미지정 지역이 포함될 가능성이 있어 Taiwan 전용 값으로 단정하지 않는다. 코드를 합산하거나 다른 범위 코드로 임의 대체하지 않는다.

지도 좌표는 팀이 설정한 국가·통계지역 대표 위치로 본사·항만·국경의 좌표가 아니다. 해안선은 기존 로컬 Natural Earth/world-atlas 자료를 재사용하고 [라이선스](MAP_LICENSE.md)를 유지한다.

## 조회·계산

조회는 `public/v1/preview/C/A/HS`, `flowCode=X`, `cmdCode=TOTAL`, `partner2Code=0`, `customsCode=C00`, `motCode=0`, `breakdownMode=classic`이다. 한 보고지역·한 연도의 전체 파트너를1회 조회하며, 최대500행 응답이거나 개수가 일치하지 않으면 잘림 가능성으로 거부한다. 국가·연도·흐름·분류·집계 레벨·숫자·중복을 검증한다. 서비스 무역·물리적 수량·금액을 섞지 않는다.

비교 연도는 **실행 기준 연도−2**라는 팀 설정으로 통일한다. 2026년 실행은2024년 자료다. 각 지역의 최신 보고 연도를 섞거나 최신치라고 부르지 않는다. UN 수정본을 재조회하므로 당시 실시간 발표 빈티지/PIT 자료는 아니다. 새 연도에 관측이 없으면 전년 값을 새 연도로 옮겨 표시하지 않는다.

브라우저에는45지역 사이의 쌍별 금액과 각 수출국의 World(파트너0) 분모만 게시한다. 분모는 양수이며 선택 파트너 합이 분모를 넘지 않는지 검증한다. 세계 총수출과 선택45지역의 합계는 다르다. 양자 금액은 원자료 decimal을 문자열로 보존해 정확한 USD 상세를 표시하고, 화면 요약은 USD bn(10억 달러) 소수3자리로 표시한다.

`수출국 전체 대비 비중 = 해당 방향 수출액 / 같은 보고국·연도 대세계 수출 ×100`이다. 들어오는 선도 **상대 보고국의 수출액**이며 선택국이 보고한 수입액이나 거울 통계로 대체하지 않는다. 선택국 상단 대세계 수출·파트너 비중은 방향 전환과 관계없이 선택국의 수출 지표다.

굵기는 `1.2 + min(3.6, log10(USD/1e9+1)×1.5)`로 금액을 표시한다. 면적·거리·물동량 척도가 아니다. 화면의 큰순/작은순/이름 정렬은 표에 적용하고 지도 상위 필터는 금액 기준이다. 0은 관측0으로 표에 남기고 선은 그리지 않는다. 결측은 미확보로 남긴다. 미보고·거부·오류를0으로 표시하지 않는다. `isReported`와 `isAggregate`는 직접 보고/집계 플래그이며 `isReported=false`를 자동으로 추정치라고 해석하지 않는다.

## PC 갱신·용량

승인된 평일08/18시 `pipeline.refresh`가 수집기를 호출한다. 실제 네트워크는 지역별30일, 코드 사전180일 캐시를 사용한다. 실패 시 이전 관측과 성공시각을 보존하며, 동일한 수치 재확인은 원자료를 복제하지 않고 확인 원장만 추가한다. 변경 시 새 로컬 빈티지에 자료를 보관한다. 401/403/429는 해당 실행의 나머지 요청을 중단하며 별도 인증·우회를 하지 않는다.

직렬 요청 사이2초를 적용하며 응답 용량 상한은 두지 않는다. 보존 사이트 추가 요청은0이다. 이 기능은 브라우저에서 UN에 자동 조회하지 않고 검증된 정적 자료만 읽는다. 원자료·조회 원장은 저장소 밖 `trade/`에 두며 공개 GitHub에는 수집·검증 코드와 작은 파생 결과만 게시한다.

최초 구축에서45지역 중42지역의2024년 수출이 확보됐고, 선택 지역 사이1840개 방향이 관측됐다. 러시아·UAE·베트남의 응답은 비어 있어 수출 방향을 미확보로 표시한다. 이 지역을 목적지로 하는 다른 보고국의 수출과 혼동하지 않는다. 실제 관측/확인 시각과 후속 변경은 화면 수집 원장에 표시한다.
