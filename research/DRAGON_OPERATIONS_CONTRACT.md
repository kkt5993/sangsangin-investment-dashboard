# 데이터 소스·현황판 계산 계약

보존한 공개 렌더러의 소스 분류 카드, 상태별 집계, 시스템 숫자, 7계열 축적 차트, 다음 갱신 예정, 모듈 날짜 구조를 독립 구현한다. 원본 사이트 재조회나 LLM 호출 없이 로컬 수집 기록과 현재 모듈 JSON을 사용한다.

## 데이터 소스

RSS 7개 제공처, ClinicalTrials.gov, SEC 13F, OpenFIGI, Sentinel-2, USGS, CelesTrak, UN Comtrade, 기업 프로필과 거시 원장의 제공처별 카드를 만든다. 분류·상태·소스/계열 검색을 지원한다. 검색은 화면에만 적용하며 PC 수집 설정을 변경하지 않는다. 소스 수는 제공처/수집 계약별 카드 수이며 독립 API 수나 기사 수가 아니다. 기업 가격·분류·옵션 등 다른 수집기의 상세 시도 상태는 기존 각 모듈 원장에서 확인하며 이 카드 목록이 전체 수집기를 포함한다고 주장하지 않는다.

각 카드에는 관측·발표 기준, 성공 수집/식별자 확인 시각, 최근 시도 시각, 성공 후 경과, 코드 캐시 시간, 관측 대상 수가 있다. 공급처 최신 발표일과 자동수집 성공을 동일시하지 않는다. UTC 오프셋이 없는 날짜는 경과 시간을 추정하지 않고 미확인으로 표시한다. 미래 시각도 정상으로 판정하지 않는다. 거시 원장은 계열별 단위/관측일/수집일을 전부 보존한다. 월간 지표가 전월 관측이라고 오류로 표시하지 않는다.

상태는 최근 오류, 자동조회 설정 필요, 미확인, 수집 대기, 빈 응답, 캐시 시간 내/경과를 구분한다. 성공 후 경과가 코드 TTL을 넘었다는 표시가 예약 실패를 의미하지는 않는다. 특히 USGS 1시간/CelesTrak 2시간 캐시는 평일 08/18시 실행 사이에 만료될 수 있다. 13F 검토 공시를 자동수집 정상으로 표시하지 않는다. 지역/기업 다건 수집기는 가장 오래된 성공 수집 시각을 표시하며 일부 실패는 이전 값이 있어도 오류 표시한다. 소스별 수량 단위가 달라 합산하지 않는다.

비밀 키·인증 여부를 검사하기 위해 로컬 설정을 읽지 않는다. 공개 필드는 명시적으로 선택하므로 원자료의 키·경로·오류 본문·HTTP 헤더가 통째로 직렬화되지 않는다. 키 등록 상태는 구현하지 않았고 공시 검토와 인증 연결을 혼동하지 않는다.

## 현황·차트·예약

차트는 관계/객체/리서치/인사이트/신호/시설/국가의 7계열을 같은 0부터 시작하는 건수 축으로 표시하고, 가로축은 게시 관측일 순서다. 원본처럼 일별 관측을 한 점으로 두며, 전체/7/30/90일 범위를 고를 수 있다. 모든 수치는 접을 수 있는 원장에 남긴다.

관계·객체·국가는 관계지도 객체 범위다. Entity360 701기업과 합치지 않는다. 리서치는 공식/팀 카탈로그이며 개인 브라우저 글은 수집하지 않는다. 신호는 지금 주목/트리거에 표시된 기업 중 실제 hits가 있는 고유 기업 수다. 원본 실시간 신호 수치와 동일한 분모가 아니다. 인사이트 수는 미산출 null로 유지하며 0점·0건이나 가짜 선으로 그리지 않는다.

이력은 스테이징에 복사된 이전 게시 JSON의 현황판을 읽고 당일 한국시간 날짜를 추가/교체한다. 과거 값을 소급 생성하지 않으며 미래/당일 기존 행은 승계하지 않는다. 검증에 실패한 스테이지의 이력은 게시하지 않는다. 정상 배포된 결과만 다음 빌드의 이력으로 이어진다. 최초 배포는 1일 관측이므로 증가 추세를 주장하지 않는다. 대형/세부 탭 완성도와 관측 건수는 별개다.

모듈 원장은 RS·모멘텀을 포함한 분석/콘텐츠 모듈의 구현 상태, 가격 기준일, 계산 생성 시각, 패널 수와 남은 범위 항목 수를 제공한다. 각 모듈로 이동할 수 있다. 브라우저에서 계산하는 평일 08시/18시 KST 카운트다운은 예약된 시각의 안내일 뿐 현재 PC 실행·배포 성공을 보장하지 않는다. 공휴일도 현재 승인된 평일 예약 기준을 따르고, 실제 수집은 거래소 관측일을 보존한다. 화면을 벗어나면 타이머를 해제한다.

전체 소스 30종의 독립 수집, 원본 인사이트 버스/키 연결, 실제 PC 실행 상태 스트리밍, 사용자 소스 설정을 PC에 전달하는 인증된 제어 API는 남은 범위다. 유료 서비스/새 인증 가입은 하지 않는다. 저장 용량 순회나 상한은 없다.
