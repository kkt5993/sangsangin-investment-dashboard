# ETF 모니터의 수익률·분배 비교

2026-09-10. 기존 로컬 현금분배·조정종가를 재계산한다. 원본 사이트에 추가 요청하거나 원본 숫자를 복제하지 않는다. 9분류73위치에 같은 상품이 중복될 수 있으며, O는 ETF가 아닌 개별 상장 리츠다.

## 화면

각 분류는 상품/1M/3M/YTD/1Y/12M분배율/관측주기/월평균/연환산/특성의10열을 제공한다. 분배율이 양수인 상품이 있으면 분배율, 없으면1Y 총수익률로 내림차순 정렬한다. 미확보 값은 뒤로 보내고 클릭 정렬·검색·투자금 변경을 지원한다. 월간 간격 관측 중 분배율 상위 상품은 월평균과1Y성과를 함께 강조한다. 막대와4기간 열지도는 접어서 추가 비교한다.

## 계산과 관측

| 항목 | 계약 |
|---|---|
| 수익률 | USD 조정종가; 1M21·3M63·1Y252관측, YTD는 직전 연도 마지막 가격 |
| 12M창 | 각 상품의 마지막 유효 가격일에서 달력1년 전을 제외하고 마지막 가격일까지 포함 |
| 현금분배 | Yahoo `Dividends` 필드의 양수 관측 합계. 날짜는 배당락일이고 실제 지급일이 아님 |
| 분배율 | 100×창 안의 주당 현금 합계/현재 시장 종가. NAV분배율·SEC수익률과 다른 값 |
| 월평균 | 입력원금×분배율/100/12; 연환산은×12. 세전, 비용 제외, 소수 주수 허용한 단순 환산 |
| 원화 표시 | 동일 시점 환전·환산의 비율이 상쇄되는 가정. 실제 환율 변화·원화 총수익률·환헤지 반영 아님 |
| 분할 | 제공처의 과거 분배액은 분할 보정되어 있으므로 분할 비율을 다시 곱하거나 나누지 않음 |
| 누락 | 가격/분배 필드 없음·최종 가격7일 초과·1년 전체 관측기간 부족이면 분배율과 환산금을 미확인으로 유지. 상품은 삭제하지 않음 |
| 0 | 전체12개월의 필드가 있고 양수 현금 관측이 없을 때만0. 미래에도 무배당이라는 뜻이 아님 |

관측 주기는 최근 최대6개 배당락일 간격의 중앙값과 최소2/3 부합을 사용한다. 주간5~9일·월간23~39일은 최소3간격, 분기65~115일은 최소2, 반기140~220일은 최소1간격이다. 나머지는 비정기·혼합 또는1회 관측으로 표시한다. 개별 현금 날짜·금액·기간·수집일·원천 링크를 원장에 제공한다. 통계적으로 주기가 관측됐다는 뜻이며 향후 지급 약속이 아니다.

## 공식 정의 대조

보존 원본은 NVDY 등을 월배당으로 표기하지만, [YieldMax 공식 일정](https://yieldmaxetfs.com/distribution-schedule/)에는 NVDY·TSLY·MSTY·CONY·ULTY가 주간 그룹에 있다. 이 오류를 복제하지 않고 관측 간격을 표시한다. [QYLD 공식 상품 설명](https://www.globalxetfs.com/funds/qyld/)은 나스닥100 주식과 지수 콜옵션 매도 구조를 설명한다. 운용사의12M분배 지표는 NAV 등을 분모로 삼으므로 여기의 시장종가 비율과 같지 않다. [TQQQ 공식 설명](https://www.proshares.com/our-etfs/leveraged-and-inverse/tqqq)은 나스닥100의 일간3배 목표다. 장기3배 성과로 표현하지 않는다.

2026-09-10에 확인한 상품 특성과 공식 링크를 설정 파일에 보관했다. 공식 일정 자동수집·실제 지급일/ROC·별도 `Capital Gains` 필드는 아직 수집하지 않는다. 현재 현금분배 필드가 상품의 모든 세무상 분배 구성요소를 포괄한다고 주장하지 않는다. 원자료 수집일이 새로워져도 공식 문서의 검토일이 자동으로 갱신되지는 않는다.
