# DRAGONGLASS 관계·시나리오·원장 계산 계약

2026-09-09 구현. 가격 기준일은 각 공개 스냅샷의 `as_of`, 관계 근거 확인일은 각 연결의 `reviewed_at`이다. 기존 시장 Beta 민감도와 공식 업종 분류도 별도 하위 화면에 유지한다. 브라우저는 공개 JSON을 읽고 상대 충격만 재계산하며 시세나 원본 사이트에 요청하지 않는다.

## 자료와 범위

- 기업22·사업 테마13·관측 거시/금2·미관측 가정2 =39객체. 사업/공급/경쟁/협업30연결과 가격 상관6연결(첫 스냅샷)이다. 상관 연결 수는 가격 갱신 시 바뀔 수 있다.
- NVIDIA FY2026 10-K 제조/경쟁, Vertiv AI Hub의 냉각·전력 기술 협업, Lilly 제품, Constellation 지속가능성 보고서의 발전 자산, Lockheed Martin 사업 설명을 확인했다. 전체 주소와 관계별 근거는 [설정](../config/relation_evidence.json)에 보관한다. 10개 사업 테마는 [ASK 설정](../config/digest_themes.json)의 회사별 공식 사업 설명을 재사용한다.

- 회사→사업 테마는 연구용 사업 연관이며 공식 GICS/KRX 업종·순수 테마 지수가 아니다. ADR TSM은 기존 공식700종목 밖 추가 Entity이며 공식 업종 미확보/RS 미산출로 표시한다.
- 원본255객체·581관계 전부를 검증한 것이 아니다. JPM·금리·금 등 연결 근거가 없는 객체는 직접 입력만 유지한다. AI CapEx/전력 수요는 실제 관측값을 만들지 않은 가정 노드다.

## 3차원 지도와 관계 대조

고정 seed의3D spring 좌표를 회전 투영한다. 회사/테마/거시/원자재/가정 필터, 관계 필터, 검색, 객체 선택, 드래그 회전, 휠/슬라이더/두 손가락 확대, 크기, 자동회전/중지, 초기화, 근거/Entity 이동을 제공한다. 화면을 떠나면 회전 프레임을 취소한다. 그래프 필터는 표시만 바꾸며 계산 관계망은 그대로다.

연결별 상관은 최근370달력일 안에서 날짜가 일치하는 최대252개 일 수익률, 최소200개, 최근 가격7일 이내, 분산이 있는 쌍만 계산한다. 결측 가격을 채우지 않으며 현지 통화 기준이다. 공개 상관 추가 연결은 공식 연결이 없는 |ρ|≥0.6 쌍 중 회사별 최대 절대 상관 쌍을 중복 제거한다. 이는 탐색 표본이며 인과관계가 아니다.

공식 관계의 순방향 가정계수와 관측 상관 부호를 일치/불일치로 대조한다. 부호 일치는 관계 검증이나 예측력 증명이 아니다. 원본의 선행/후행 발견 엔진은 미연결이다.

## 1~3단계 상대 충격

[Python 엔진](../pipeline/relation_model.py)과 [화면 엔진](../docs/relation-views.js)은 다음 공개 구조를 독립 구현한다. 각 시나리오의 기본3단계 결과를 공개 JSON에도 보존하여 두 구현을 교차 검사한다.

| 관계 | 순방향 | 역방향 |
|---|---:|---:|
| supplies | .28 | .72 |
| competes | −.50 | −.50 |
| part-of | .42 | .55 |
| exposed-to | .50 | .50 |
| powers | .28 | .62 |
| correlated | .62 | .62 |
| builds | .22 | .50 |
| hosts | .58 | .30 |
| pressures | −.55 | −.20 |
| drives | .62 | .30 |
| comention | .45 | .45 |
| collaborates (팀 추가) | .35 | .35 |

각 계수에 `(0.7 + 0.1 × weight) × 0.9`를 곱한다. weight1은 확인한 관계의 존재를 반영한 모형 설정이며 거래규모나 추정 탄력성이 아니다. 단일 충격 범위는±2, 최대3단계, 중간 절대 강도0.03 미만 경로는 중단한다. 같은 경로 안에서 객체를 재방문하지 않는다. 한 일차 입력에서 한 도착지로의 최강 절대 경로만 채택하고, 서로 다른 일차 입력은 부호를 보존해 합한다. 동률은 짧은 경로·관계 ID 순으로 결정한다. 각각의 기여와 출처를 보존한다.

실현 상관 연결은 기본 전파에서 제외한다. 사용자가 포함하면 관측 상관 부호를 전달계수에 곱한다. 원본의 음의 상관을 양의 계수로 전파하는 처리와 다르며, 이는 명시적인 팀 보정이다. 상관 절댓값을 경제 탄력성으로 해석하지 않는다.

중심성은 +1 기본 충격의 도달 |강도|≥0.05를 대상으로 `절대 강도 합 + 0.15 × 도달 객체 수`다. 가정상 연결성 순위이며 기업 중요도의 객관적 추정치가 아니다. 화면 중심성은 기본3단계·상관 제외 고정값이다.

## 8개 시나리오와 패널

금리 재상승, AI CapEx 둔화, TSMC 공급 차질, 전력 병목, HBM 가속, 지정학 격화, GLP-1·GIP 확산, 위험선호 후퇴. 공개 원본의 일차 입력0.2~0.7을 대응 객체에 매핑하며 [presets](../pipeline/relation_views.py)를 정본으로 삼는다. 금리 bp/CapEx 변동률로부터 추정한 주가 수익률이 아니다.

선택기 → 일차 입력 → 기업 도달 범위(|강도|≥0.12) → 양·음 방향별 최대8개 순위(|강도|≥0.06) → 기여별 경로/출처 → 전체 객체 원장 → 실행 결정 영향 순서다. 단일 충격 화면도 같은 경로 패널을 사용한다. 순효과0의 상쇄에도 원래 기여를 남긴다.

## 개인 결정과 관측 상관

원장은 기존 V2 localStorage를 읽기만 하며 새 저장 규칙/확률을 만들지 않는다. 제안·청산·휴지통은 포트폴리오 집계에서 제외한다. 현재 실행 기록의 `방향 × 비중/100 × 상대 강도`를 합하며 **% NAV 손익으로 표시하지 않는다**. 0 비중은0, 알려진 객체의 모형 경로 없음도 모형 내0, 관계망 밖 객체/미입력 비중/미지정 방향은 미산출이다. 하나라도 미산출이면 전체 강도는 없고 계산 가능한 부분합만 표시한다.

결정별 프리모템은 Long/Short 방향을 반영한8개 기본 가정 중 최소 강도와 경로다. 경로 없음은 위험이 없다는 뜻이 아니다. 확신도에서 성공확률·기대수익·권장비중을 자동 만들지 않으며 기존 EV는 사용자의 이익/손실/확률 입력만 사용한다.

원장 상관은 Entity 전체702종목에 대해 최근370달력일 내 **전체 종목 합집합의 최근252개 관측일 창**을 고정한다. 쌍별 유효 관측200개 이상, 최근 가격7일 이내, 결측 채움 없음이다. 그래프의 쌍별252개 공통 관측 창과 다를 수 있다. 실행 Long의 양의 비중, 중복 종목 제거 후 가용 쌍 단순평균·가용/전체 쌍 수·상위 쌍을 표시한다. 비중 가중 집중도나 환헤지 상관이 아니다.

전송은 정렬 ID의 아래삼각 row-major `i*(i-1)/2+j`에 Int16 little-endian 상관×10000, 결측32767, 관측 수 Uint8을 base64로 저장한다. 자기상관도 관측200개·유효 분산이 있을 때만1이다. 양자화 오차 최대0.00005. 원자료 가격은 PC에만 유지한다.

## 검사와 남은 차이

방향 비대칭, 경쟁 음수, 단일 입력 최강 경로, 다중 입력 상쇄, 순환/단계 제한, 음의 상관 opt-in, 결측/상수/오래된 가격, 압축 행렬 round-trip, 공개8가정 Python/JS 일치, 원장0/미산출/실행 필터, 실제 UI 이벤트 콜백, SVG 래스터를 확인한다. 브라우저 QA를 수행했다는 뜻은 아니다.

전체 공급망, 실제 고객 매출비중/충격계수, 위성 관측, 구루/임상/13F 원문, 팀 공용 DB는 남아 있다. 이 모듈을 전체 원본 데이터 복제 또는 인과 예측 엔진 완료로 표시하지 않는다.
