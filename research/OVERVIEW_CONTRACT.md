# Overview 좌표·적층 레이더·주도주

2026-09-09. [계산](../pipeline/overview_state.py), [화면](../docs/overview-views.js), [결과](../docs/data/overview_state.json). 원본에 다시 접속하지 않고 보존한 `app.js`의 `_TESS_CFG`, `_CROWD_CFG`, `tessRadar`, `initWormhole`과3개 JSON을 대조했다. 원본 거시 국면는 **6축**, 시장 쏠림은5축이다. 단순5축이라는 이전 메모를 정정한다.

## 공통 기간과 변환

36개 월별 시점: 과거35개 월말과 현재 기준일. 현재 월말이면 그 월말을 포함한36개다. 2년 전/1년 전/6개월 전/현재는 각각 인덱스11/23/29/35. 현재 월중 스냅샷과 과거 확정 월말은 날짜가 다르므로 월중 여부를 표시한다.

원단위 관측과 z를 함께 보존한다. z는 해당 시점까지 최대120개 월별 관측, 최소60개 유효 관측, ddof0 표준편차다. 상수는 z 미산출이고0으로 넣지 않는다. 원본의 정확한 z 준비 기간은 미공개이므로 팀 설정이며 수치 동등성을 주장하지 않는다. 과거 원점의 z에 이후 값을 사용하지 않는다. 자료 자체는 최신 수정 빈티지여서 실시간 PIT 자료는 아니다.

WALCL·WTREGEN은 USD million, RRPONTSYD는 USD billion이어서 RRP에1000을 곱한다. 각 기준일에 이용 가능한 마지막 값을 조합하며 주간 구성값은12일, 일간 RRP는7일을 넘겨 유지하지 않는다. WTREGEN은 주간평균, WALCL은 수요일 관측이므로 정확히 같은 순간의 순자금 잔고가 아닌 근사다. YoY 분모는 양수일 때만 허용한다. 12개월 비교는 달력 월 시점이며 현재 월중/과거 월말 차이가 있다.

CP는 BEA 전산업 이익이며 S&P500 구성기업 EPS/순이익 합계가 아니다. 분기 시계열을 완전한 분기 달력으로 재정렬한 후4분기 YoY를 계산해 결측 분기를 건너뛰지 않는다. GDP도 명목 USD bn SAAR를 사용한다.

월별 CPI/산업생산은 관측월말+1개월, GDP/CP는 분기말+2개월(CP Q4는+3개월), FEDFUNDS는 관측월말+7일, 유동성 구성값은 관측+1일을 팀 이용 시점으로 둔다. 원자료에 공표일 빈티지가 전부 포함되어 있지 않으므로 이 규칙은 실제 공표 이력 인증이 아니다. 월별 관측95일/분기200일을 넘기면 미산출이다. 값·관측기간 끝·팀 이용 시점·복수 구성원의 관측일을 보존한다.

## 주도주 패널

현재 재무 캐시에서 USD/KRW 시총을 USD로 환산한 상위50표본을 만든다. KRW는 기준일까지의 USD/KRW 가격으로 환산하고7일 초과 시 미산출한다. 전체 세계 시총 상위50을 수집했다는 의미가 아니다. 가격12개월 수익률과 최근 분기 순이익 YoY가 있는 종목에 대해 주도력을 구한다.

`0.42×z(log시총)+0.35×z(모멘텀)+0.23×z(NI YoY)`이며 뒤2입력은 적격 표본5/95분위로 winsorize한다. 현재 표본의 단면 ddof0 z, 상수 입력의 상대 기여는0이다. 실제 분기 전년동기 이익이 양수일 때만 성장률을 사용하고 흑자전환을 통상 성장률로 만들지 않는다. 상위10의 깊이=log시총, 색=12M 모멘텀, 크기=분기NI 성장으로 표현한다. 원본의 미공개 극단치 처리/시총 변환을 같은 것으로 주장하지 않는다.

시총·가격·재무 수집 시각·결산 기간·환율일은 다를 수 있어 별도로 보존한다. 현재 기록은 역사 리밸런싱 성과나 매수 추천이 아니다.

## 표시와 검증

왼쪽3D의 바닥X×Z4분면, 높이Y, 색/크기/후광, 36개월 궤적·현재 바닥 투영과4시점 마커를 제공한다. 오른쪽6각형/5각형은 오래된 시점을 위, 현재를 아래에 적층하고 측벽/연결선을 그린다. 시장 쏠림 중앙에는18개 동심원 깊이 구조와10개 주도주를 둔다. 회전 슬라이더·드래그·자동회전/중지·초기화·종목 선택/호버가 동작한다. 원단위 표와 출처 기간도 제공한다.

좌표는±2.2z, 레이더 반경은±2z로 시각적으로만 제한하며 실제 숫자는 자르지 않는다. 필수 위치 축이 결측이면 해당 점과 인접 선을 생략한다. 레이더 결측을0으로 대체하지 않는다. 화면 이동 시 프레임을 취소하고, 늦게 도착한 데이터가 다른 화면을 덮지 않도록 보호한다. 브라우저 QA 대신 계산 fixture·실제 이벤트 콜백·SVG 래스터 검사를 수행했다.
